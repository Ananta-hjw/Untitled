# 검사 캐릭터 — Spine 작업용 분리 PNG

최근 수정한 검사 캐릭터를 기준으로 만든 투명 배경 PNG 20개입니다. `.spine` 프로젝트, 리깅, 애니메이션은 포함하지 않습니다.

## 구성

- `images/`: 개별 파츠 20개. 파일명의 `r/l`은 캐릭터 본인의 오른쪽/왼쪽입니다.
- `parts_sheet.png`: 전체 파츠를 확인할 수 있는 원본 시트입니다. Spine용으로 패킹한 런타임 atlas는 아닙니다.
- `parts_manifest.json`: 파일명, 픽셀 크기, 시트에서의 추출 위치, 권장 부모 관계입니다. Spine 가져오기용 skeleton JSON은 아닙니다.

## 파츠 이름

| 파일명 | 부위 |
|---|---|
| head | 얼굴·앞머리·귀 장식 |
| hair_back | 뒤쪽 긴 머리카락 |
| hair_ponytail | 묶은 머리 |
| torso | 목·상의·가슴 가죽끈 |
| pelvis | 골반·벨트·재킷 아래 자락 |
| upper_arm_r / upper_arm_l | 위팔·소매, 오른쪽 어깨 보호대 포함 |
| forearm_r / forearm_l | 아래팔·팔 보호대 |
| hand_r_grip | 검을 잡는 오른손 |
| hand_l | 왼손 |
| thigh_r / thigh_l | 허벅지 |
| shin_r / shin_l | 종아리·부츠 윗부분 |
| foot_r / foot_l | 부츠 발부분 |
| sword | 검 |
| scabbard | 빈 칼집 |
| sash | 허리의 파란 천 |

## Spine에서 조립

1. 새 skeleton을 만들고 Images 경로를 이 폴더의 `images`로 지정합니다.
2. pelvis를 기준으로 torso와 목·머리 뼈를 배치합니다.
3. 어깨 → 위팔 → 아래팔 → 손, 골반 → 허벅지 → 종아리 → 발 순서로 뼈대를 연결합니다.
4. sword는 오른손 뼈에, scabbard는 몸통 뼈에 연결합니다. 머리카락은 머리 뼈에, sash는 골반 뼈에 연결합니다.
5. 권장 뒤→앞 그리기 순서: 뒤쪽 머리 / 칼집 → 뒤쪽 팔다리 → 골반·몸통 → 앞쪽 팔다리 → 머리 → 검을 덮는 손가락. 포즈에 맞춰 바꿔주세요.

## 조립 시 확인할 점

생성형 이미지로 재구성한 파츠 초안입니다. 각 PNG는 파츠별로 잘라져 있으며, 같은 캔버스 위치에 놓기만 하면 자동으로 조립되는 구조는 아닙니다. 부위별 스케일·위치·회전과 관절 겹침을 Spine에서 맞춰야 합니다. 손은 검의 손잡이에 맞춰 조정하고, 필요하면 손가락을 검 앞쪽 슬롯으로 분리하세요. 어깨 소매·부츠 연결부는 겹침으로 맞추고, 크게 꺾는 동작에서는 메시와 가중치를 조정하세요. 머리카락·천의 부드러운 움직임에는 추가 메시 또는 파츠 분할이 필요할 수 있습니다. 단일 시점용이며 별도의 측면·후면 파츠는 포함하지 않습니다.

## 제작 방식

내장 이미지 생성 도구로 파츠를 재구성한 후, 시트에서 개별 RGBA PNG로 분리했습니다.

사용 프롬프트 요약: 최근 검사 디자인·얼굴·비율을 유지한 3/4 정면 Spine용 파츠 20개. 얼굴, 뒤 머리, 포니테일, 몸통, 골반, 좌우 위팔·아래팔·손·허벅지·종아리·발, 검, 칼집, 허리 천을 분리하고 가려진 관절 부분을 보완. 투명 배경, 글자·그림자·효과 제외.
