# 몬스터 SD 원화

기존 캐릭터의 채색과 선화에 맞춰 이미지 생성 도구로 제작한 전신 기본 자세입니다. 슬라임·물방울 버섯은 창조신 아우레아 계열(물), 쇠비늘 도마뱀은 파괴신 드라칸 계열(금속), 서리 딱정벌레는 수호신 바르덴 계열(얼음)의 하급 권속입니다(`docs/story-chapter1.md`). 시아의 `sd_idle.png`는 화풍 참고로만 사용했습니다.

| 파일 | 인물 | 디자인 |
| --- | --- | --- |
| `slime/sd_idle.png` | 슬라임 | 연녹색의 물 같은 몸, 둥근 바닥 돌기와 작은 기포, 단순한 눈과 다문 입. 가장 약한 근접형 몬스터의 기본 모습. |
| `waterdrop-mushroom/sd_idle.png` | 물방울 버섯 | 물방울이 맺힌 푸른 갓, 크림색 몸과 짧은 팔다리, 소심하게 경계하는 다문 입. 물방울을 발사하는 원거리형 몬스터의 기본 모습. |
| `iron-scale-lizard/sd_idle.png` | 쇠비늘 도마뱀 | 갈색 피부와 크림색 배, 겹친 철색 비늘·황동빛 능선·호박색 눈. 낮은 몸과 긴 꼬리로 돌진형 실루엣을 표현했습니다. |
| `frost-beetle/sd_idle.png` | 서리 딱정벌레 | 서리 무늬가 있는 하늘색 얼음 껍질, 짙은 청록색 몸과 짧은 다리·더듬이. 단단한 정면과 둥근 방어형 실루엣을 표현했습니다. |

네 원본은 1254 × 1254 투명 RGBA PNG입니다. 배경·바닥 그림자 없이 제작했으며, 전체 몸과 물방울·꼬리·더듬이가 캔버스 안에 들어갑니다. 슬라임의 녹색은 몸의 색이며 식물 능력을 뜻하지 않습니다. 버섯은 포자 대신 물방울을 쓰는 디자인입니다. 도마뱀은 불이나 용의 날개를 추가하지 않고 금속 비늘로, 딱정벌레는 바위 대신 얼음 껍질로 원소를 구분했습니다. 두 번째 묶음도 물방울 버섯 원화를 화풍 참고로만 사용했습니다.

## 습격용 권속 SD 원화

`docs/story-chapter1.md`의 습격 그래픽 제작 기준에 따라 다음 세 종류의 기본 자세를 추가했습니다. 기존 쇠비늘 도마뱀은 화풍 참고로만 사용했으며, 집행자는 새 추적자의 부식된 표면과 색감도 참고했습니다.

| 파일 | 권속 | 디자인 |
| --- | --- | --- |
| `ashen-moth/sd_idle.png` | 잿빛 나방 · 하급 | 잿빛·탁한 보라색의 닳은 날개, 깃털형 더듬이와 작은 몸. 가까운 날개 끝에 소량의 부식성 가루를 표현한 비행 기본 자세. |
| `corrosion-tracker/sd_idle.png` | 부식의 추적자 · 중급 | 낮게 엎드린 네 발 짐승형. 먹빛 몸과 마모된 껍질, 독성 발톱으로 골목을 수색하는 실루엣을 표현했습니다. |
| `corrosion-executioner/sd_idle.png` | 부식의 집행자 · 중급 정예 | 갈라진 가면과 해진 장막, 비대칭으로 커진 부식된 팔. 길을 막아서는 육중한 직립 자세이며 사령관의 장례 예복·모래시계와 구분했습니다. |

세 파일 모두 1254 × 1254 투명 RGBA PNG입니다. 입은 다물거나 가면으로 가렸으며, 부식된 표면은 실제 소멸·허무나 몸의 투명화를 뜻하지 않습니다. 기본 SD 원화만 추가했으며 이동·공격 시트와 게임의 임시 습격 그래픽 교체는 아직 포함하지 않습니다. 생성 원본은 `/workspace/generated_images/`에 보존합니다.

## 기존 4종 이동·공격 모션

각 몬스터 폴더에 1254 × 1254 투명 PNG 시트 4장과 `animation_frames.json`을 추가했습니다. 한 시트는 4행 × 4열이며, 몬스터당 64프레임, 전체 256프레임입니다. 기본 원화는 그대로 보존합니다.

| 시트 | 행 순서 | 열 순서 |
| --- | --- | --- |
| `walk_cardinal.png` | 아래·왼쪽·오른쪽·위 | 대기·첫걸음/압축·통과/상승·반대 걸음/착지 |
| `walk_diagonal.png` | 왼쪽 아래·오른쪽 아래·왼쪽 위·오른쪽 위 | 위와 동일 |
| `attack_cardinal.png` | 아래·왼쪽·오른쪽·위 | 대기·준비·타격·복귀 |
| `attack_diagonal.png` | 왼쪽 아래·오른쪽 아래·왼쪽 위·오른쪽 위 | 위와 동일 |

- 슬라임: 몸을 눌렀다가 늘이며 이동하고, 탄성으로 몸통을 내미는 돌진.
- 물방울 버섯: 짧은 발걸음과 갓의 흔들림, 갓을 젖혔다 숙이는 물방울 발사 준비·반동. `projectile.png`는 오른쪽을 향한 별도 물방울 원화이며, 비행·회전은 게임에서 구현해야 합니다.
- 쇠비늘 도마뱀: 네 발과 꼬리를 번갈아 움직이는 보행, 몸을 낮춘 정면 돌진.
- 서리 딱정벌레: 다리와 껍질을 흔드는 보행, 머리와 껍질을 낮춰 밀치는 공격.

## 좌표 생성과 확인

저장소 루트에서 `python3 tools/build_monster_frames.py`를 실행하면 시트 경계와 투명 배경을 검사하고 프레임 좌표를 다시 생성합니다. 같은 방향의 대기 자세를 기준으로 고정 중심·바닥점과 크기 보정을 적용하여 공격 중 늘어나는 몸을 매 프레임 재정렬하지 않습니다.

`npm run dev` 실행 후 `/tools/monster-animation-preview.html`에서 4종·8방향의 대기, 이동, 공격을 비교할 수 있습니다. 기본 재생 속도는 초당 8프레임이며, 속도 조절과 일시정지를 지원합니다. 공격은 확인 편의를 위해 반복 재생합니다. 좌표 파일의 공격 설정은 단발 동작이며 준비·타격·복귀 자세를 구분합니다.

현재 추가한 것은 모션 원화·측정 좌표·미리보기입니다. 게임의 기존 임시 그래픽, 이동 AI, 투사체 비행, 타격 판정에는 아직 연결하지 않았습니다. 실제 적용 시 바닥 접촉점과 발사 위치를 조정해야 합니다. 피격·사망 시트와 모바일용 축소본도 별도 작업입니다. 그림 안의 크기는 실제 게임에서의 몸집이나 난이도 배율을 확정하지 않습니다. 생성 원본은 `/workspace/generated_images/`에 보존합니다.
