# 안개 까마귀 — 혼돈 · 환영 / 하급

무리로 날아와 덮치는 작고 빠른 하급 마물. 피격되면 잠깐 흐릿한 분신 하나를
남기고 본체가 다른 자리로 옮겨 가는 사용자 지정 콘셉트에 맞춰 제작했다.
깜빡이 요정보다 약하고 빠른 무리형이라는 관계는 추후 행동·수치 연결 기준이다.
이동·8방향 공격·피격 후 잔상과 위치 이동을 게임에 연결했다. 고갯길에는 3마리씩 두 무리가 나온다.
체력 22·공격력 5·이동 속도 205가 레벨 1 기준이며 실제 지역에서는 레벨 보정한다.
아직 없는 깜빡이 요정과의 상대 밸런스는 그 몬스터 구현 뒤 비교해야 한다.

## 외형

작고 날렵한 먹빛·회청색 까마귀, 은청색 눈, 깃 끝과 꼬리의 옅은 안개.
부식·독 계열과 구분하며 갑옷·해골·뿔을 넣지 않았다. 본체는 선명하게,
잔상은 은회색의 흐릿한 깃털과 풀리는 가장자리로 구분했다.
OpenAI 이미지 생성 도구로 제작했다. 기존 잿빛 나방은 화풍만 참고했으며,
새 까마귀 기본 원화를 이동·공격·분신 그림의 외형 기준으로 사용했다.

날갯짓 열은 수평 대기 → 날개 올림 → 아래로 내리침 → 다시 올림이다.
공격 열은 대기 → 준비 → 부리·발톱을 내민 덮치기 → 비행 복귀다.
이동 32프레임과 공격 32프레임, 합계 64프레임이며 뒤를 향한 행은 등과 꼬리가 보인다.
투명 배경·각 칸의 여백을 검사했다. 실제 재생은 캔버스를 단순히 정수 4등분하지 않고
측정한 `animation_frames.json`의 좌표를 사용한다.

## 실행용 사본과 확인

```
PYTHONDONTWRITEBYTECODE=1 python3 tools/build_fog_crow_assets.py
```

원본을 보존하며 같은 크기의 시트 WebP 4장, `sd_idle-512.webp`,
`afterimage-512.webp`, 프레임 좌표를 만든다. 초당 이동 10장·공격 12장은 미리보기
제안이며 공격 판정이나 밸런스를 확정한 값은 아니다. 비행 높이·몸 중심점·실제 표시
크기는 게임에 연결할 때 확인해야 한다. 날개가 다른 자세마다 커지지 않도록
한 방향의 그림들은 고정 원점과 배율을 공유한다.

개발 서버의 `/tools/monster-animation-preview.html?group=chapter2`에서 8방향
이동·공격을 비교할 수 있다. 분신 전용 원화는 한 방향이며, 다른 방향의 순간 잔상은
현재 비행 프레임을 흐리게 남기는 방식으로 구현할 수 있다. 분신에 그림자를 넣지 않고,
재출현 위치의 통행 가능 여부와 피격 후 반복 발동 간격은 AI 연결 단계에서 처리한다.

## 전투 연결

`MonsterSprite`가 공중 대기 중에도 4자세로 날갯짓한다. `Enemy`는 짧은 준비 후
잠근 방향으로 최대 140단위 덮치며 이동 경로를 따라 명중을 검사한다.
살아남은 피격은 실제 피해를 받은 뒤 최대 150단위의 안전한 자리로 이동하고,
650ms 동안 충돌·체력·그림자가 없는 잔상 하나를 남긴다. 재사용 간격은 2400ms이며,
안전한 자리가 없으면 이동하지 않는다. 사망·재생성 때 잔상을 정리한다.
잔상은 게임 시계를 사용해 메뉴·대화와 함께 멈춘다.
전용 분신 원화는 오른쪽 아래 방향에, 다른 방향은 현재 비행 프레임에 옅은 색을 입혀 쓴다.
개발 확인: `?map=east-pass` 또는 `?map=south-field&monsters=fog-crow`.
