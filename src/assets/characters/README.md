# 리네아와 시아 캐릭터 이미지

## 구성

- `linea/dialogue.png`: 리네아의 기본 대화용 전신 일러스트.
- `linea/sd_idle.png`: 리네아의 정면 SD 기본 이미지.
- `sia/dialogue.png`: 시아의 기본 대화용 전신 일러스트.
- `sia/dialogue_successor.png`: 네이룬의 계승자로 선택된 이후 시아의 별도 대화용 전신 일러스트. 1024 × 1536 투명 RGBA PNG입니다.
- `sia/sd_idle.png`: 시아의 정면 SD 기본 이미지.
- `sia/sd_successor_idle.png`: 흑화한 계승 이후 시아의 정면 SD 기본 이미지. 1254 × 1254 투명 RGBA PNG이며 `sia/dialogue_successor.png`의 표정·의상·책을 반영했습니다.

모든 이미지는 투명 배경 RGBA PNG입니다. 대화용 이미지는 전신을 담고 있어 UI에서 무릎 위 구도로 표시할 수 있습니다. SD 이미지는 단일 정지 포즈이며 방향별 이동 애니메이션 시트가 아닙니다. 리네아와 시아는 마을 NPC와 대화창에 연결했습니다. 게임 연결: 로웬 마을 사람들은 `tools/build_rowen_assets.py`가 만든 작은 WebP 사본(`dialogue-768.webp`, `walk_*-60.webp`)으로 게임에 들어가 있습니다(`src/world/npcs.ts`). 원본은 그대로 둡니다.

## 디자인

- **리네아**: 시온의 다정하지만 당찬 소꿉친구. 밤색 긴 머리와 옆 땋은 머리, 녹색 눈, 청록색 의상과 약초 주머니로 친근하고 활동적인 인상을 표현했습니다.
- **시아**: 시온의 밝고 따뜻한 여동생. 어두운 머리와 호박빛 눈으로 남매의 연결감을 주고, 붉은 리본과 장밋빛 원피스, 작은 책으로 생기와 호기심을 표현했습니다.
- **계승 이후 시아**: 사용자 요청에 따라 고민과 갈등을 겪으며 흑화한 모습으로 표현했습니다. 기존 얼굴과 붉은 리본, 책은 유지하고, 웃음을 거둔 지친 눈빛과 억누른 표정, 먹빛·검붉은 의상과 비대칭 망토, 빛바랜 자수와 재처럼 해지는 옷자락으로 소멸신의 계승자라는 인상을 더했습니다. 성물이나 향후 행동을 확정하는 설정은 아닙니다. 원래 마을 일러스트와 SD는 보존했고, 계승 이후 대화용·SD 이미지는 별도 파일로 제작했습니다. 게임에는 아직 연결하지 않았습니다.

외형과 소품은 이번 이미지 제작을 위한 디자인 제안이며, 직업이나 상세 나이를 확정하는 설정은 아닙니다.

## 제작 기준

이미지 생성 도구로 제작했습니다. 시온의 `../hero/dialogue/neutral.png`를 대화용 화풍 기준으로, `../hero/academy/player_walk.png`를 SD 화풍 기준으로 참고했습니다. 각 SD 이미지는 먼저 제작한 해당 캐릭터의 대화용 일러스트를 참고해 의상과 외형을 맞췄습니다. 시온 원본 캐릭터 시트의 출처는 `../hero/academy/README.md`를 참조하세요.
