# 세레나의 간호 동작

기존 `sd_idle.png`를 참조해 이미지 생성 도구로 제작한 `nursing-source.png`를 보존한다. 은빛 머리카락이 섞인 낮은 쪽머리, 잿빛 녹색 숄, 자주색 치마와 앞치마를 유지했다.

4열 × 2행 원화의 위 행은 무릎을 꿇고 왼쪽 위 환자를 돌보는 네 자세, 아래 행은 물그릇과 깨끗한 수건을 준비하는 네 자세다. 자택의 오른쪽 병상에서는 간호 그림과 발 원점을 함께 반전한다. 환자·침대·가구는 원화에 포함하지 않는다.

```bash
python3 tools/build_serena_nursing.py
```

스크립트는 투명 여백을 잘라 각 자세를 높이 304px로 포장한다. 무릎을 꿇은 자세는 `npcStoryActions.ts`에서 서 있는 자세보다 낮게 표시하며 이름표와 대화 표시 높이도 함께 바뀐다. 원화는 변경하지 않는다.

간호 30초 → 물수건 준비 5초 → 병상 복귀를 반복한다. 치유소에서는 두 침대 사이의 통로를 거치며 침대를 가로지르지 않는다. 리네아가 집으로 옮겨지면 같은 방에서 간호를 계속한다. 대화하면 현재 동작을 잠깐 멈췄다가 이어 간다.

습격 중 안전 확인 대화를 마치면 광장에서 북쪽 출입구까지 충돌을 피하며 걸어 나간다. 재접속 위치는 퀘스트 진행에서 복원한다. 별도의 대피·회복 저장 키는 추가하지 않는다.
