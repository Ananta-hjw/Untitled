# 계승자 대화용 일러스트

`docs/story.md`의 다섯 계승자 설정을 바탕으로 제작한 기본 대화용 이미지입니다. 모두 1024 × 1536 투명 배경 RGBA PNG이며 머리부터 무릎 부근까지 보이는 구도입니다. 시아는 기존 `sia/dialogue.png`를 유지합니다.

| 파일 | 인물 | 나이와 디자인 기준 |
| --- | --- | --- |
| `bram/dialogue.png` | 수호의 계승자 브람 | 50대(외형 기준 56세). 짧은 회색 머리와 수염, 절제된 표정과 닳은 실전 장비로 무뚝뚝하고 현실적인 피난민 보호자를 표현했습니다. 신의 상징이나 발광 효과 대신 검과 여행 장비에 집중했습니다. |
| `mirel/dialogue.png` | 창조의 계승자 미렐 | 20대 초반(외형 기준 22세). 금발과 녹색 눈, 아이보리·금색 의복과 새싹을 감싼 손으로 다정함과 헌신을 표현했습니다. 이후 사건을 암시하는 악의적 표정은 넣지 않았습니다. |
| `kairen/dialogue.png` | 질서의 계승자 카이렌 | 30대 중반(외형 기준 35세). 단정한 청흑색 머리, 곧은 자세와 정돈된 은색 갑옷으로 엄격하고 원칙적인 기사단장을 표현했습니다. |
| `velka/dialogue.png` | 파괴의 계승자 벨카 | 20대 중반(외형 기준 26세). 짧은 적갈색 머리와 강한 체격, 직설적인 눈빛과 수선한 실용복으로 거칠지만 독립적인 생존자를 표현했습니다. |
| `razen/dialogue.png` | 혼돈의 계승자 라젠 | 실제 나이 미상. 은회색 머리, 여유로운 반웃음과 비대칭 남색·자주색 여행복, 서신으로 능글맞고 속내를 숨기는 정보상을 표현했습니다. |

나이 범위와 성격은 스토리 문서를 따르며, 정확한 수치와 머리색·의상·소품은 이번 외형 디자인을 위한 제안입니다. 새싹이나 서신 등은 성물의 확정 디자인이 아닙니다.

## SD 기본 이미지

다섯 인물의 폴더에 각각 `sd_idle.png`를 추가했습니다. 모두 1254 × 1254 투명 배경 RGBA PNG이며 전신 정면 기본 포즈입니다. 각자의 `dialogue.png`를 외형 기준으로, 리네아의 `linea/sd_idle.png`를 SD 화풍 기준으로 참고해 이미지 생성 도구로 제작했습니다.

- 브람: 나이 든 얼굴과 수염, 절제된 표정, 닳은 실전 장비와 여행 담요를 유지했습니다.
- 미렐: 금발과 부드러운 미소, 밝은 의상과 새싹을 감싼 자세를 유지했습니다.
- 카이렌: 단정한 머리와 곧은 자세, 은색 갑옷과 검 위에 모은 손을 유지했습니다.
- 벨카: 강인한 체형과 당찬 눈빛, 적갈색 머리와 수선한 실용복을 유지했습니다.
- 라젠: 여유로운 반웃음, 은회색 머리와 비대칭 의상, 서신과 손짓을 유지했습니다. SD는 좁은 눈매와 또렷한 얼굴선으로 성숙함을 표현하되, 눈가와 입가의 주름을 줄여 지나치게 나이 들어 보이지 않도록 조정했습니다. 실제 나이 미상 설정은 유지합니다.

기존 시온의 `../hero/dialogue/neutral.png`를 대화용 화풍 참고로 이미지 생성 도구로 제작했습니다. 기준 이미지의 원본 캐릭터 시트 출처는 `../hero/academy/README.md`를 참조하세요. 이번 작업은 이미지 추가이며 게임의 대화 UI나 캐릭터 데이터에 연결하지 않았습니다. SD는 단일 정지 포즈이며 방향별 이동·공격 애니메이션 시트가 아닙니다.
