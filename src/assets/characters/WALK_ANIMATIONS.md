# NPC 이동 시트

리네아·시아·루안의 기존 `sd_idle.png`를 바탕으로 이미지 생성 도구로 제작했습니다. 시아는 흑화 이전의 마을 모습이며, 루안은 50대 초반 외형을 유지합니다. 기존 정지 이미지와 대화용 이미지는 보존했습니다.

2차로 세레나·도란·메리나를 추가했습니다. 세레나는 낮게 묶은 머리와 숄·앞치마, 도란은 회색 수염과 가죽 앞치마·망치, 메리나는 붉은 단발과 금빛 조끼·청록 치마·장부를 유지합니다. 도란은 망치를 내리고 이동하며 공격 모션이 아닙니다.

3차는 헤르만·에일라·테온입니다. 헤르만은 백발과 수염·올리브색 외투·지팡이·봉인 편지, 에일라는 옆으로 묶은 머리와 약초 자수 복장·약초·붕대, 테온은 붉은 갈색 머리와 푸른 경비복·어깨 갑옷·팔에 낀 투구를 유지합니다. 테온의 검은 칼집에 둡니다. 에일라 대각선 시트는 칸 경계에 닿던 부분을 수정하고 방향별 배율로 크기를 맞췄습니다.

4차는 로제타·베르넬·페른입니다. 로제타는 새치가 섞인 곱슬머리와 두건·앞치마를 유지하고 양손으로 수프 쟁반을 듭니다. 베르넬은 둥근 안경과 은빛 머리카락·보라색 외투·수첩·석판을, 페른은 푸른 띠 모자와 콧수염·청록색 외투·주황 목도리·침낭이 달린 배낭을 유지합니다. 기존 마을 NPC 12명의 이동 시트가 모두 준비됐습니다.

5차로 계승자 브람·미렐·카이렌·벨카·라젠 5명의 이동 시트를 추가했습니다. 각자의 최신 `sd_idle.png`를 외형 기준으로, 루안의 이동 시트를 방향과 배열 참고로 이미지 생성 도구로 제작했습니다. 입은 다물고 걷습니다.

- 브람: 50대의 얼굴과 짧은 회색 수염, 낡은 갑주·망토·여행 짐. 검은 칼집에 둡니다.
- 미렐: 금발과 땋은 머리·리본, 상아색 치유사 복장. 양손으로 새싹 화분을 안정적으로 들고 걷습니다.
- 카이렌: 짙은 남청색 머리와 은색 갑주·남청색 망토. 검은 칼집에 둡니다.
- 벨카: 붉은 머리와 옆 땋은 머리, 얼굴 흉터·민소매·붕대·올리브색 바지. 무기를 추가하지 않았습니다.
- 라젠: 회보라색 머리와 낮게 묶은 머리, 보라색 외투·청회색 목도리·가방·봉인 편지. 기존 성인 외형을 유지합니다.

계승자 5명은 이미지와 프레임 좌표, 미리보기까지 준비한 상태이며 게임 NPC로 배치하지 않았습니다. 계승 이후 시아의 별도 의상은 이번 제작에 포함하지 않습니다.

## 파일 구성

각 인물 폴더에 아래 파일이 있습니다.

- `walk_cardinal.png`: 1254 × 1254 투명 RGBA, 4열 × 4행. 위에서부터 아래·왼쪽·오른쪽·위 방향.
- `walk_diagonal.png`: 같은 크기의 투명 시트. 위에서부터 왼쪽 아래·오른쪽 아래·왼쪽 위·오른쪽 위 방향.
- `walk_frames.json`: 원본 이미지 영역, 원점, 방향별 크기 보정과 재생 순서.

각 행의 0열은 대기, 1~3열은 걷기 포즈입니다. 인물당 8방향 × 4포즈 = 32프레임이며, 마을 NPC 12명 384프레임과 계승자 5명 160프레임으로 총 17명 544프레임입니다. 권장 걷기 순서는 초당 8프레임으로 `[1, 2, 3, 2]`를 반복합니다. 정지하면 해당 방향의 0열을 표시합니다. 시아는 책을 안고 걸으며, 루안은 검을 칼집에 넣은 상태입니다.

## 좌표 측정과 확인

```bash
python3 tools/build_npc_frames.py
# 계승자만 다시 측정할 때
python3 tools/build_npc_frames.py --characters bram mirel kairen velka razen
npm run dev
```

개발 서버의 `/tools/npc-walk-preview.html`에서 열일곱 명의 여덟 방향을 함께 재생하고 대기·걷기와 재생 속도를 비교할 수 있습니다. 다운로드용 독립 미리보기는 각 차수와 전체 모음의 `preview.html` 파일에 시트와 좌표를 내장했습니다.

측정 스크립트는 원본 픽셀을 변경하지 않습니다. 알파 128 이상의 외곽으로 각 프레임을 측정하고, 머리 중심을 발바닥 높이로 투영한 원점으로 좌우 흔들림을 줄입니다. 방향별 대기 높이를 기준으로 배율을 공유해, 별도로 생성한 대각선 시트의 크기를 보정합니다. 원점은 자동 측정 초안이므로 실제 NPC에 연결할 때 이동 경로와 겹침 순서, 발 미끄러짐을 함께 확인해야 합니다.

이미지 생성 시 방향이 중복된 시아·루안의 대각선 시트를 수정했고, 시아의 대각선 프레임은 칸 경계에 닿지 않도록 재배치했습니다. 게임에서는 페른을 뺀 열한 명을 이 시트로 그립니다(`src/entities/Npc.ts`). 장사하는 도란·메리나·로제타는 제자리에 서서 시온을 돌아보고, 나머지는 자기 자리 주변을 돌아다닙니다. 플레이어와는 부딪히지 않습니다. 공격 애니메이션은 포함하지 않습니다.
