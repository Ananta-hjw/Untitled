# NPC 이동 시트 · 1차 3명

리네아·시아·루안의 기존 `sd_idle.png`를 바탕으로 이미지 생성 도구로 제작했습니다. 시아는 흑화 이전의 마을 모습이며, 루안은 50대 초반 외형을 유지합니다. 기존 정지 이미지와 대화용 이미지는 보존했습니다.

## 파일 구성

각 인물 폴더에 아래 파일이 있습니다.

- `walk_cardinal.png`: 1254 × 1254 투명 RGBA, 4열 × 4행. 위에서부터 아래·왼쪽·오른쪽·위 방향.
- `walk_diagonal.png`: 같은 크기의 투명 시트. 위에서부터 왼쪽 아래·오른쪽 아래·왼쪽 위·오른쪽 위 방향.
- `walk_frames.json`: 원본 이미지 영역, 원점, 방향별 크기 보정과 재생 순서.

각 행의 0열은 대기, 1~3열은 걷기 포즈입니다. 인물당 8방향 × 4포즈 = 32프레임, 세 명 합계 96프레임입니다. 권장 걷기 순서는 초당 8프레임으로 `[1, 2, 3, 2]`를 반복합니다. 정지하면 해당 방향의 0열을 표시합니다. 시아는 책을 안고 걸으며, 루안은 검을 칼집에 넣은 상태입니다.

## 좌표 측정과 확인

```bash
python3 tools/build_npc_frames.py
npm run dev
```

개발 서버의 `/tools/npc-walk-preview.html`에서 세 명의 여덟 방향을 함께 재생하고 대기·걷기와 재생 속도를 비교할 수 있습니다. 다운로드용 독립 미리보기는 `preview.html` 파일에 시트와 좌표를 내장했습니다.

측정 스크립트는 원본 픽셀을 변경하지 않습니다. 알파 128 이상의 외곽으로 각 프레임을 측정하고, 머리 중심을 발바닥 높이로 투영한 원점으로 좌우 흔들림을 줄입니다. 방향별 대기 높이를 기준으로 배율을 공유해, 별도로 생성한 대각선 시트의 크기를 보정합니다. 원점은 자동 측정 초안이므로 실제 NPC에 연결할 때 이동 경로와 겹침 순서, 발 미끄러짐을 함께 확인해야 합니다.

이미지 생성 시 방향이 중복된 시아·루안의 대각선 시트를 수정했고, 시아의 대각선 프레임은 칸 경계에 닿지 않도록 재배치했습니다. 시트 재생용 데이터와 미리보기만 추가했으며, 게임의 NPC 이동 AI·충돌·실제 배치에는 아직 연결하지 않았습니다. 공격 애니메이션은 포함하지 않습니다.
