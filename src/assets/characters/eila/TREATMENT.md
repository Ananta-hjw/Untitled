# 에일라의 치료 동작

기존 `sd_idle.png`를 참조해 이미지 생성 도구로 제작한 `treatment-source.png`를 보존한다. 크림색 망토·올리브색 잎무늬 옷·회갈색 머리·푸른 눈·붕대 주머니를 유지했다.

원화는 4열 × 2행이다. 위 행은 왼쪽 환자를 향해 붕대와 찜질포를 대는 네 자세, 아래 행은 휴대용 절구로 약초를 준비하는 네 자세다. 자택의 오른쪽 병상을 치료할 때에는 치료 그림과 발 원점을 함께 좌우 반전한다. 환자나 가구는 원화에 포함하지 않는다.

```bash
python3 tools/build_eila_treatment.py
```

스크립트는 투명 여백을 잘라 키 304px로 포장하고, 부츠 바닥을 기준으로 발 원점을 측정한다. `treatment.webp`와 `treatment-frames.json`을 재생성하며 원화는 변경하지 않는다.

구조 전 광장에서는 응급 약품을 준비한다. 리네아를 구조한 뒤에는 치유소, 안정되어 옮긴 뒤에는 리네아의 집에서 치료한다. 병상에서 20초 치료하고 약품 자리에서 5초 준비한 뒤 돌아온다. 걷는 동안 작업 그림을 해제하고 기존 8방향 걷기를 사용한다. 대화 중과 직후에는 현재 작업 자세를 잠깐 멈췄다가 이어 가며, 재접속하면 같은 환자의 병상에서 치료를 시작한다.
