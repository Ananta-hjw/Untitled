# 가짜 종 사내의 어머니

`docs/story-chapter2.md`의 이름 없는 조연. 아들이 모르간에게 진 약값 빚과
연관된 인물이며, 서브 퀘스트 「약값」에서 시온이 약을 전해 준다.
`bell-ringer-mother`는 파일 구분용 식별자이며 새 이름을 확정하지 않았다.

## 디자인

아들과 닮은 긴 코와 갈색 눈, 희끗한 머리를 낮게 땋아 올린 성인 여성.
약 60대라는 외형 기준은 제작용 제안이다. 병의 종류나 나이를 스토리 설정으로
추가하지 않았다. 야윈 체형과 창백하고 지친 얼굴, 조금 굽은 어깨로 병색을 표현하며
의식이 또렷하고 대화할 수 있는 상태다. 입을 다문 걱정스러운 표정이다.

수선한 오트밀색 숄·회청색 원피스·녹슨 붉은 소매·회색 무릎 담요·갈색 치마와
낡은 신발을 사용했다. 붉은 소매는 아들의 목수건과 색을 맞췄다.
작은 나무 걸상에 앉아 손수건을 쥐고 쉬는 모습이며, 약병이나 마법 효과를 넣지 않았다.

## 원본과 실행용 사본

OpenAI 이미지 생성 도구로 제작했다. 초상화는 아들의 원화를 가족 외형과 화풍의
참고로 사용했고, SD는 어머니의 초상화와 아들의 SD를 참고했다.

| 파일 | 용도 |
| --- | --- |
| `dialogue.png` | 앉은 전신 대화 원화, 1024×1536 RGBA |
| `sd_idle.png` | 앉아서 쉬는 기본 SD, 1199×1312 RGBA |
| `dialogue-768.webp` | 대화용 작은 사본 |
| `sd_idle-256.webp` | 게임용 작은 SD 사본 |
| `sd_idle.json` | 걸상 다리와 신발의 바닥 접촉 범위를 기준으로 한 원점 |

```
PYTHONDONTWRITEBYTECODE=1 python3 tools/build_bell_ringer_mother_assets.py
```

원본은 보존하고 투명 여백과 머리·신발·걸상 다리의 잘림을 검사한다.
걸상은 인물 그림에 포함되어 있어 맵에 별도 걸상을 겹쳐 놓지 않는다.
좌석을 포함한 바닥 접점으로 깊이와 충돌을 정해야 한다.
이번 작업은 이미지와 실행용 자료 준비까지이며, NPC 등록·대화·약 전달 사건에는
아직 연결하지 않았다. 누운 자세·방향별 걷기·전투 동작은 포함하지 않는다.
