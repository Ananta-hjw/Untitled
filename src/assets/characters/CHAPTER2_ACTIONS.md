# 2장 전투·종 운반·설치 이미지

각 인물의 `sd_idle.png`를 기준으로 이미지 생성 도구로 제작했다. 기존 머리·의상·소품과 흙빛 색감, SD 비율을 유지하며 장면에 맞춰 자세를 바꿨다. 모든 원본과 게임용 이미지에는 투명 알파 채널이 있다. 조안과 에반은 나무 노·장대로 대응하며 검이나 갑옷을 추가하지 않았다.

| 인물/소품 | 원본 | 자세와 순서 |
| --- | --- | --- |
| 조안 | `joan/combat-source.png` | 2열 × 2행: `attack` 양손 노 공격, `guard` 노로 막기, `hit` 피격, `injured` 한쪽 무릎을 꿇고 버티기 |
| 에반 | `evan/defense-source.png` | 2열 × 2행: `guard` 장대로 방어, `knockback` 뒤로 밀려나기, `hit` 피격, `fatigued` 무릎을 꿇고 버티기 |
| 모르간 | `morgan/work-source.png` | 2열 × 2행: `lift-ready` 밧줄을 잡고 함께 들어 올릴 준비, `hammer-wedge` 들보의 쐐기 박기, `tie-rope` 들보에 밧줄 묶기, `work-hit` 작업 중 피격·균형 유지 |
| 에반·모르간 공동 운반 | `../chapter2/bell-carry-source.png` | 2열 × 1행: `carry-step-1`·`carry-step-2`. 에반이 앞, 모르간이 뒤에서 같은 운반 장대를 어깨에 메고 종 하나를 함께 옮긴다 |
| 사당 종 | `../chapter2/shrine-bell.png` | 추를 되찾아 수리한 상태. 갈대·강물 무늬와 녹청, 굵은 가장자리, 위쪽 고리와 쇠 추가 있다 |

종·공동 운반 이미지 파일은 `src/assets/chapter2/`에 있다. 공동 운반의 종도 이 소품을 외형 기준으로 제작했다. 마르타가 든 작은 견본 종과는 별개다.

## 게임용 파일

`python3 tools/build_chapter_two_actions.py`로 생성한다. 원본 PNG는 보존한다.

- 기존 전투·운반 자세는 해당 폴더의 `<자세>.webp`로도 저장한다.
- 조안은 `combat.webp`와 `combat-frames.json`, 에반은 `defense.webp`와 `defense-frames.json`, 모르간은 `work.webp`와 `work-frames.json`으로도 묶었다. 인물 시트는 모두 1024 × 768이며 각 칸은 512 × 384다.
- 공동 운반은 `src/assets/chapter2/bell-carry.webp`·`bell-carry-frames.json`과 자세별 WebP로 저장한다. 시트는 1920 × 512, 각 칸은 960 × 512다.
- 사당 종의 작은 사본은 `src/assets/chapter2/shrine-bell.webp`다.
- 시트마다 같은 배율과 발 기준점을 사용한다. 무릎을 꿇은 자세를 서 있는 자세만큼 확대하지 않는다. 모르간 설치 그림은 짧은 들보·쇠 고리를 포함하며 원점은 들보 위 발의 지지 위치에 맞춘다. 주변 사당 배경에 합칠 때 들보가 중복되지 않도록 한다.

## 에반 장면 시트

에반의 기존 8방향 걷기, 노 공격, 방어·피격, 종 공동 운반, 도르래 줄 당기기에 이어 나루와 안개섬 장면을 준비했다. 아래 시트는 모두 `evan/`에 원본 PNG, 2열 × 2행 1024 × 768 WebP, 프레임 JSON이 있다.

| 시트 | 왼쪽 위부터 읽는 순서 |
| --- | --- |
| `riverbank` | 강가에 앉아 기다리기 → 일어서기 → 상류를 가리키기 → 손을 들어 여울 통행을 말리기 |
| `mooring` | 계류줄 잡기 → 매듭 느슨하게 하기 → 줄 빼내기 → 풀린 줄 걷기 |
| `rowing` | 노 내밀기 → 물에 담그기 → 당기기 → 노 들어 올리기 |
| `cocoon-guard` | 조안의 고치 앞에 무릎 꿇기 → 노로 고치 앞 막기 → 발이 실에 묶여 버티기 → 실이 풀려 발을 빼기 |
| `reunion` | 조안의 어깨를 짚기 → 포옹 → 안도하며 미소 짓기 → 팔을 내줘 조안을 부축하기 |

노 젓는 시트는 에반과 노를 담는다. 배·강·계류 말뚝·바위·고치·안개 실은 맵 소품 또는 효과로 배치한다. 재회는 두 인물이 함께 그려진 컷이다.

## 핀 장면 시트

`finn/walk_cardinal.png`과 `finn/walk_diagonal.png`은 방향마다 대기 1컷, 걷기 3컷으로 구성된다. `walk_frames.json`과 60% WebP는 기존 NPC 걷기 로더를 따른다.

| 시트 | 왼쪽 위부터 읽는 순서 |
| --- | --- |
| `finn/night-watch` | 솜을 끼고 깨어 있기 → 시온의 소매를 잡고 깨우기 → 아버지가 간 방향을 가리키기 → 안도하며 아버지를 끌어안기 |
| `finn/kite-flight` | 얼레 잡기 → 줄 풀기 → 줄 당기기 → 줄을 잡고 균형 유지하기 |

두 장면 시트는 원본 PNG, 2열 × 2행 WebP와 프레임 JSON으로 구성된다. 밤 장면의 마지막 컷은 핀과 여관 주인을 함께 그렸다. 연 날리기 컷은 핀과 얼레를 담으며, 화면에 보이는 연은 별도 소품으로 배치한다.

## 모르간·마르타 장면 시트

두 사람 모두 방향마다 대기 1컷과 걷기 3컷을 그렸다. `walk_cardinal`·`walk_diagonal`의 원본 PNG, 60% WebP, `walk_frames.json`을 기존 NPC 걷기 로더에서 읽는다. 마르타는 대장간에 어울리게 짧은 보폭을 사용한다.

| 시트 | 왼쪽 위부터 읽는 순서 |
| --- | --- |
| `morgan/pole-row` | 노 내밀기 → 물속 말뚝 더듬기 → 노 당기기 → 다시 들어 올리기 |
| `morgan/confession` | 고개 숙이고 서기 → 무릎을 굽히기 → 꿇어앉기 → 손을 펴고 고백하기 |
| `morgan/bell-ring` | 종줄에 손 뻗기 → 줄 잡기 → 당겨 종 울리기 → 줄 놓으며 자세 회복하기 |
| `marta/bell-repair` | 종 추 살피기 → 추 고리 끼우기 → 망치 들기 → 추 고정 부위 두드리기 |
| `marta/wax-earplugs` | 밀랍 떼기 → 손으로 굴리기 → 끝 모양 다듬기 → 귀마개 내밀기 |

특수 시트에는 원본 PNG, 2열 × 2행 WebP와 프레임 JSON이 있다. 배·물속 말뚝과 사당 종·들보는 별도 소품이며, 기존 공동 운반과 쐐기·매듭 그림은 종을 설치하는 앞 단계에 사용한다.

## 나루 여관 주인·도르 장면 시트

두 사람의 `walk_cardinal`·`walk_diagonal`은 방향마다 대기 1컷과 걷기 3컷으로 구성된다. 60% WebP와 `walk_frames.json`을 기존 NPC 로더에서 읽는다. 여관 주인의 몽유는 `sleepwalk` 시트를 사용한다.

| 시트 | 왼쪽 위부터 읽는 순서 |
| --- | --- |
| `fog-innkeeper/river-wake` | 화들짝 깨어남 → 한쪽 발이 물로 빠져 휘청임 → 발을 빼며 뒤로 물러남 → 이마를 짚고 진정함 |
| `dor/tend-fire` | 쪼그려 앉아 잔가지 놓기 → 부싯돌과 쇠 준비 → 부싯돌 치기 → 손으로 바람 막기 |

두 장면은 원본 PNG와 2열 × 2행 WebP·프레임 JSON으로 구성된다. 물과 불꽃은 별도 효과나 소품으로 배치한다. `river-slip`의 기준점은 제방에 남은 발의 높이에 맞춰, 빠지는 발이 기준점 아래로 내려오게 했다.

## 적용 범위

기존 전투·운반·설치 원화는 인물 동작 12개, 두 사람 공동 운반 2개, 종 소품 1개로 구성된다. 이 원화의 각 동작은 단일 키 포즈이며 방향별 애니메이션이나 연속 공격 프레임이 아니다. 원본의 칸 경계에서 노·장대·신체·밧줄이 잘리지 않는지 확인했고, 포장 스크립트에서도 경계와 원점을 검사한다.

이번 작업은 이미지와 프레임 자료 제작이다. 기존 정면 SD 연결은 유지하며, 조안의 실제 전투 그림 전환과 에반·모르간의 사건별 행동 재생은 별도 연결이 필요하다. 종 운반은 두 인물과 종이 함께 그려진 그룹 이미지이므로 이 장면에서는 두 NPC의 개별 그림을 동시에 겹쳐 표시하지 않는다. 운반 준비 자세에는 종이 포함되지 않는다.

스토리의 설치 순서는 도르래 고정 → 에반이 줄을 당기고 모르간이 종을 이끌어 올리기 → 보조 줄 안전 고정 → 에반이 고치로 이동 → 모르간의 마지막 매듭과 높이·방향 조정이다. 기존 쐐기·매듭 그림은 이 순서에 맞춰 사용한다. 전반에는 에반의 기존 `rope-pull` 시트를 사용한다. 도르래는 별도 소품으로 배치한다.
