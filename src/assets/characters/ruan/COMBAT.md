# 루안의 전투 모습

53세 검술 스승의 새치·짧은 회색 수염·남색 코트·황토색 허리 천을 유지한 SD 전투 원화입니다. 수정한 무표정의 `sd_idle.png`와 기존 걷기 시트를 참고해 이미지 생성 도구로 제작했습니다.

- `combat-source.png`: 공격·막기·피격·부상 순서의 2×2 투명 원화.
- `attack.webp`: 검을 앞으로 내지르는 공격 자세.
- `guard.webp`: 검을 기울여 몸 앞에서 막는 자세.
- `hit.webp`: 피격되어 뒤로 밀리는 자세.
- `injured.webp`: 한쪽 무릎을 꿇고 검에 몸을 지탱하는 생존한 부상자 자세. 피나 노출된 상처는 없습니다.
- `combat.webp`, `combat-frames.json`: 1024×768 아틀라스와 4개 영역. 개별 파일은 512×384입니다.

재생성: `python3 tools/build_npc_combat.py --characters ruan` (기존 `python3 tools/build_ruan_combat.py`도 지원). 공격 검끝이 원화의 중앙선을 넘으므로 실제 빈 공간에서 분리하며, 네 자세에 같은 축소 배율을 사용해 부상 자세만 커지는 것을 방지합니다.

게임에서는 `Npc`의 습격 전투 상태에 연결합니다. 가까운 적에게 접근해 공격하고, 정면 공격을 막거나 피해를 받으면 막기·피격·부상 자세로 전환합니다. 전투 그림은 앞 대각선 정적 포즈이며 왼쪽 상대는 좌우 반전합니다. 접근 이동은 기존 8방향 걷기를 사용합니다. 부상자는 전투를 멈추고 대화는 계속할 수 있습니다. 평소에는 기존 대기·순찰을 사용합니다.

북쪽 전투 직후부터 퀘스트 상태로 부상 자세를 복원합니다. 습격 후에는 붕대를 감고 앉아서 요양합니다.

부상 시점·저장·회복·목재 수리 연결은 [수비대 회복 동작](../defender-recovery/RECOVERY.md)을 참고합니다.
