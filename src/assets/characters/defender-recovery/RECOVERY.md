# 수비대의 부상 회복과 복구 동작

`recovery-source.png`는 기존 루안 부상·테온 SD·일반 병사 SD를 참조해 이미지 생성 도구로 제작한 투명 원화입니다. 원본을 수정하지 않고 보관합니다.

- 2열 × 4행: 루안의 붕대 감은 앉은 휴식, 테온의 붕대 감은 고정 경계, 병사의 무릎 꿇은 회복, 병사의 목재 수리. 각 동작은 두 프레임입니다.
- `python3 tools/build_defender_recovery.py`로 `recovery.webp`, `recovery-frames.json`을 재생성합니다. 같은 동작의 두 프레임은 같은 축소 배율을 사용합니다.
- 급성 부상에는 기존 `combat.webp`의 `injured`를 재사용합니다. 기존 걷기·전투 원화는 유지합니다.
- 테온은 습격 첫 전투 직후(step 1), 루안은 북쪽 전투 직후(step 5)부터 부상 자세로 전투를 중단합니다. 습격 완료 뒤 루안은 앉아서 쉬고, 테온은 붕대를 감고 남문에서 고정 경계합니다.
- 실제 전투에서 쓰러진 병사는 `untitled-rpg.defender-injuries`에 ID를 저장합니다. 재진입·재접속해도 부상 상태를 유지하고, 습격 후에는 기존 배치 자리에서 회복합니다. 사망 상태를 의미하지 않습니다.
- 다음 날의 수색과 초기 치료를 거쳐 `first-sword`가 완료되면 테온·병사는 원래 업무에 복귀합니다. 루안은 계속 요양하며 대화·검술 전수를 진행합니다.
- 회복 중 대화·퀘스트 표시는 유지하고, 순찰과 수리는 중단합니다. 건강한 광장 서쪽 병사만 목재 수리 두 프레임과 기존 걷기를 번갈아 사용합니다.
