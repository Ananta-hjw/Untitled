# 2장 물안개 나루 인물 원화

`docs/story-chapter2.md`의 역할과 성격을 바탕으로 이미지 생성 도구로 제작한 대화용 전신 일러스트다. 기존 페른과 마을 인물의 따뜻한 중세 판타지 화풍을 기준으로, 절제된 흙빛 색감과 천·가죽의 질감을 사용했다. 모두 1024 × 1536 RGBA PNG이며 투명 영역이 있다.

| 파일 | 인물 | 외형과 성격의 연결 |
| --- | --- | --- |
| `evan/dialogue.png` | 에반, 늙은 사공 | 마른 체격과 햇볕에 그을린 주름, 짧은 회색 수염, 지친 눈빛. 기운 회녹색 외투와 계류 밧줄로 강에서 오래 일한 생활을 표현했다. 남청색 모자와 밧줄의 푸른 천은 딸 조안의 색과 연결된다. |
| `joan/dialogue.png` | 조안, 열여덟 살의 사공이자 첫 동료 | 단단하고 활동적인 체형, 밤색 땋은 머리와 남청색 머릿수건, 차분하고 의지 있는 표정. 남청색 작업 조끼와 황토색 허리띠, 밧줄과 나무 노로 강을 잘 아는 길잡이를 표현했다. 물고기 목걸이는 가족을 기억하는 디자인 소품이다. |
| `marta/dialogue.png` | 마르타, 청동 종을 만들던 노장인 | 은빛으로 땋은 머리와 단호한 눈매, 굵은 팔과 오래된 화상 자국. 벽돌색 작업복, 그을리고 녹청이 묻은 가죽 앞치마, 망치와 주물 집게로 숙련된 장인을 표현했다. 손에 든 작은 종은 직업을 보여 주는 견본이며 사건의 사당 종이 아니다. |
| `morgan/dialogue.png` | 모르간, 나루의 후원자로 보이는 밀수꾼 | 단정한 머리와 콧수염, 절제된 미소와 손님을 맞는 손짓. 자주색 외투와 장부, 창고 열쇠로 마을에 자리 잡은 상인의 모습을 표현했다. 처음부터 악인으로 읽히는 의상이나 표정은 피하고, 소맷단의 작은 수선 자국으로 검소하고 계산적인 면을 담았다. |

| `dor/dialogue.png` | 도르, 고개 쉼터의 약초꾼 노인 | 가늘고 긴 은빛 수염과 온화한 주름, 마르고 굽었지만 안정적인 자세. 세이지색 망토와 높은 약초 바구니, 구부러진 나무 지팡이, 약초 묶음으로 산길에 익숙한 생활인을 표현했다. 마법사의 지팡이나 장식은 사용하지 않았다. |

페른은 기존 `fern/dialogue.png`를 유지한다. 구체적인 나이(조안 제외), 복식, 목걸이 등은 외형 제작 기준이며 새로운 사건이나 과거사를 확정하는 설정이 아니다.

## 사용 상태

여섯 인물의 원화를 인물별 `dialogue.png`로 저장했다. 게임 NPC·대화창에는 아직 연결하지 않았으며 SD 정지 이미지, 방향별 이동 시트, 조안의 전투 시트는 이번 제작에 포함하지 않는다. 게임에서 사용할 작은 WebP 사본도 아직 생성하지 않았다. 기존 NPC 이미지와 스토리 수정본은 보존한다.
