# 리네아의 회복 자세

기존 `sd_idle.png`를 참조해 이미지 생성 도구로 제작한 투명 원화다. 갈색 머리·땋은 머리와 리본·녹색 눈·금색 잎무늬 청록 의상을 유지했다. 침대와 방은 기존 실내 객체를 사용하며 새 그림에는 인물·덮은 이불·일지만 포함한다.

- `clinic-rest-source.png`: 위는 의식 없이 누운 모습, 아래는 눈을 뜬 채 누운 모습. 머리가 왼쪽인 치유소 침대용이다.
- `home-rest-source.png`: 집 침대에 기대 증상 일지를 쓰는 모습.
- `recovery.webp`, `recovery-frames.json`: 잘라서 축소·포장한 런타임 그림과 기준점.

```bash
python3 tools/build_linea_recovery.py
```

원화를 변경하지 않고 투명 여백만 자른다. 치유소 자세는 너비 512px, 자택 자세는 높이 640px로 포장한다. 표시 배율은 `npcStoryActions.ts`의 `bodyHeight`로 맞춘다. 몸의 위치·병상 옆 대화 위치·침대 위 표시 깊이는 `chapterOne.ts`에서 원화 픽셀 좌표를 실내 월드 좌표로 함께 변환한다.

구조 이후 치유소에서 의식을 되찾고, `first-sword` 완료 후 자기 집으로 옮긴다. 별도 저장 키 없이 퀘스트에서 상태를 복원한다. 대화·대기·재접속으로 서 있는 그림으로 돌아가지 않는다. 세레나와 에일라는 환자와 같은 실내에 배치한다.
