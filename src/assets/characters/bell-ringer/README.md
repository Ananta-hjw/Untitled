# 가짜 종을 울리던 사내 — 모르간의 부하

`docs/story-chapter2.md`의 이름 없는 조연. 창고 뒤 갈대밭에서 놋쇠 종을 울리다
시온에게 붙잡힌다. 아픈 어머니의 약값을 모르간에게 빚지고 있어 입을 열지 못한다.
`bell-ringer`는 파일 식별자이며 새 이름을 확정한 것이 아니다.

## 디자인

짧고 흐트러진 검은 머리, 갈색 눈, 수염 자국, 피로와 경계심이 드러나는 성인 남성.
약 30대라는 외형 기준은 제작용 제안이며 스토리의 확정 나이가 아니다.
회녹색의 수선한 작업복·녹슨 붉은 목수건·밧줄과 천 주머니·해진 각반으로
나루의 일꾼이라는 인상을 주었다. 입을 다문 긴장한 표정이며 과장된 악당 미소는 없다.

귀 안쪽의 노란 밀랍은 밤에 종소리를 막는 단서다. 귓불의 귀걸이가 아니라
귀 안쪽을 메운 밀랍으로 표현했다. 오른손의 작은 황색 놋쇠 손종은 가짜 신호용이며,
초록 녹이 슨 사당의 청동 종과 구분한다. 손은 나무 손잡이를 쥐고 추는 종 안에 있다.

## 원본

- `dialogue.png`: 대화용 전신 원화, 1024×1536 RGBA.
- `sd_idle.png`: 정면 기본 SD, 1108×1420 RGBA.
- `ring-source.png`: 종을 울리는 SD 4자세, 1108×1420 RGBA, 2행×2열.
  왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 순서다.

OpenAI 이미지 생성 도구로 제작했다. 대화용은 모르간의 원화를 화풍 참고로만 사용했고,
SD는 새 초상화와 여관 주인의 SD 비율을 참고했다. 종 동작은 새 SD를 기준으로 만들었다.
원본 PNG는 보존한다.

## 게임용 사본

```
PYTHONDONTWRITEBYTECODE=1 python3 tools/build_bell_ringer_assets.py
```

- `dialogue-768.webp`
- `sd_idle-256.webp`, 발 기준 원점 `sd_idle.json`
- `ring-1.webp`~`ring-4.webp`
- `ring.webp`: 1024×320, 한 칸 256×320의 4칸 가로 시트.
- `ring-frames.json`: 원점·프레임 좌표·권장 초당 4프레임 반복 재생.

동작은 종을 낮게 들기 → 들어 올리기 → 바깥으로 흔들기 → 되돌리기다.
같은 배율과 발 위치로 패키징했으며 손종을 포함한 실루엣·투명 여백을 검사했다.
NPC·대화 초상화·종 울리기 4자세를 연결했다. `npcs=support` 확인 모드에서 볼 수 있고,
말을 걸면 종을 멈춘다. 가짜 종 본편 사건은 해당 지역이 구현될 때 배치한다.
일반 방향별 걷기나 전투 동작은 포함하지 않는다.
