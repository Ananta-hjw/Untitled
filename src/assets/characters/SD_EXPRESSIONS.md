# SD 기본 표정

필드에서 서 있거나 걷는 SD는 입을 다문 표정을 기본으로 사용합니다. 미소는 눈매와 볼, 가볍게 올라간 입꼬리로 표현하고 치아·혀·벌어진 입 안은 보이지 않게 합니다.

이미지 생성 도구로 시아·루안·도란·메리나·로제타·베르넬·테온·페른·벨카의 `sd_idle.png`를 수정했습니다. 기존에 입을 다문 다른 인물과 시아의 계승 이후 이미지는 유지했습니다. 대화용 일러스트에는 이 규칙을 일괄 적용하지 않습니다.

벨카를 제외한 위 여덟 명은 `walk_cardinal.png`와 `walk_diagonal.png`의 보이는 얼굴에도 같은 기준을 적용합니다. 프레임 배치·방향·걷기 포즈는 기존 시트를 따르고 좌표 데이터는 수정된 원본에서 다시 측정합니다. 게임에서 이미 사용하는 `sd-300.webp`와 시아·루안의 `walk_*-60.webp`도 원본에 맞춰 다시 내보냅니다.

미술 수정은 이미지 생성 도구로 진행하며, 프레임 측정과 실행용 크기·포맷 변환은 기존 에셋 스크립트를 사용합니다. 새 인물이나 시트를 추가할 때도 정면·측면·대각선의 입 모양을 함께 확인합니다.
