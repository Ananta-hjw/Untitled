# 습격 이후 주민의 복구·구호 작업

기존 다섯 주민의 `sd_idle.png`를 참조해 이미지 생성 도구로 제작한 원화입니다. 복장·나이·머리색을 유지하고, 작업을 내려다보는 차분한 표정으로 만들었습니다.

`work-source.png`는 투명 원본 2열 × 5행입니다. 행 순서는 헤르만의 피해 기록, 도란의 쇠붙이 수리, 메리나의 붕대·물약 정리, 로제타의 담요 준비, 베르넬의 확대경 조사입니다. 각 동작 두 프레임이며 원본을 그대로 보관합니다.

`python3 tools/build_village_relief.py`로 `work.webp`와 `work-frames.json`을 생성합니다. 행 사이의 실제 간격을 측정해 분리하고, 같은 동작 두 프레임에 같은 배율을 적용합니다. 베르넬의 무릎 꿇은 동작은 게임에서 더 낮게 표시합니다.

- 헤르만·베르넬: 습격 이후 기존 세 지점을 순환합니다. 각각 7초 기록·8초 조사 후 기존 걷기 그림으로 다음 현장에 갑니다.
- 메리나·로제타: 습격 중에는 치유소에서 구호 물품·담요를 준비합니다. 습격 후에는 원래 가게·여관에서 준비를 이어갑니다. 상점·숙박 및 카운터 앞 대화 위치는 유지합니다. 로제타는 담요와 두 손이 가려지지 않도록 기존 대화 위치인 카운터 앞 바닥에 서서 작업합니다.
- 도란: 습격 중에는 치유소 입구를 지킵니다. 이후 대장간의 모루 옆에서 작은 철제 수리 부품을 줄로 손질합니다. 기존 모루·탁자를 그림에 중복해서 넣지 않았습니다.
- 대화 중 작업이 잠시 멈추고 이후 재개됩니다. 퀘스트 표시가 있으면 작업 문구보다 우선합니다.
- 배치는 완료한 퀘스트로 복원합니다. 별도의 주민 작업 저장 키는 추가하지 않았습니다.
