# 물안개 나루 여관 주인 — 핀의 아버지

`docs/story-chapter2.md`의 이름 없는 조연. 종소리에 이끌려 잠든 채 강가로
걸어가다 시온에게 구조되며, 이후 자신이 들은 어머니의 목소리를 증언한다.
`fog-innkeeper`는 파일 구분용 식별자이며 인물의 새 이름을 확정한 것이 아니다.

## 디자인

핀의 밤색 머리·주근깨·녹갈색 눈을 이어 받은 중년의 아버지.
짧은 수염과 관자놀이의 흰머리, 건장하고 약간 살집 있는 체형으로 소년과 구분했다.
황토색 조끼·빛바랜 남색 목수건·수선한 갈색 앞치마·방 열쇠·줄무늬 행주로
일하는 여관 주인의 모습을 표현했다. 나이 약 40대라는 기준은 제작용 외형 제안이다.
입을 다문 다정하지만 지친 표정이며, 잠든 모습은 눈을 감고 고개를 조금 숙인다.

## 원본

- `dialogue.png`: 대화용 전신 원화, 1024 × 1536 RGBA.
- `sd_idle.png`: 정면 기본 SD, 1108 × 1420 RGBA.
- `sleepwalk-source.png`: 잠든 채 걷는 SD 4자세, 1108 × 1420 RGBA, 2행 × 2열.
  왼쪽 위부터 오른쪽 아래 순서로 재생한다. 정면에서 약간 오른쪽을 향한 한 방향이다.

OpenAI 이미지 생성 도구로 제작했다. 대화용은 핀의 대화 원화를 참고했고,
SD는 새 초상화와 핀의 SD를, 잠든 동작은 새 SD를 참고해 외형과 화풍을 맞췄다.
원본 PNG는 보존한다.

## 게임용 사본

`python3 tools/build_fog_innkeeper_assets.py`로 생성:

- `dialogue-768.webp`
- `sd_idle-256.webp`, `sd_idle.json`
- `sleepwalk-1.webp`~`sleepwalk-4.webp`
- `sleepwalk.webp`: 1024 × 320, 4칸 가로 시트, 한 칸 256 × 320.
- `sleepwalk-frames.json`: 발 기준 원점과 권장 재생 속도(초당 4프레임).

잠든 동작은 같은 배율과 발바닥 높이에 맞춰 패키징했다.
NPC 등록·대화창·잠든 걸음 4자세·말을 걸면 깨어나는 동작을 연결했다.
나루 본편 지역과 강가 구조 사건은 아직 없어 본편 배치는 추가하지 않았다.
개발 확인: `?map=east-stream&npcs=innkeeper&sleepwalk=1&companion=none`.
`Npc.startSleepwalk(path)`로 충돌을 따르는 느린 걸음을 시작하고 `wake()`로 깨운다.
일반 방향별 걷기와 전투 동작은 포함하지 않는다.
