# 로웬 마을 아트

기존 시작 마을의 `../home.png`를 초기 화풍 참고로 이미지 생성 도구로 제작했습니다. 사용자 요청에 따라 동일한 집에 소품만 바꾸는 방식 대신, 건물마다 층수·실루엣·지붕 모양·재료와 색을 다르게 설계했습니다.

| 파일 | 구성 |
| --- | --- |
| `residential.png` | 투명 RGBA 2 × 2 시트. 위 행: 가족 집·수련소. 아래 행: 촌장 집·치유소. |
| `commerce.png` | 투명 RGBA 2 × 2 시트. 위 행: 대장간·잡화점. 아래 행: 여관·경비 초소와 행상 수레. |
| `overview.png` | 불투명 전체 마을 조감도. 위 두 시트의 건물 외형을 참고해 생성했습니다. |

위 세 원본은 모두 1536 × 1024 PNG입니다. 건물 시트는 표시·충돌 좌표가 아직 정의되지 않은 원본 아트이며, 실제 게임에서는 적절한 크기와 바닥 영역을 측정해야 합니다. 조감도는 건물과 인물까지 그려진 컨셉 이미지로, 현재 게임의 지면 텍스처를 대체하지 않습니다.

NPC와 시설의 대응, 배치 의도는 `docs/rowen-village.md`에 정리했습니다. 게임 코드와 기존 시작 마을 이미지는 아직 변경하지 않았습니다.

## 추가 건물·실내 원화

`linea-house.png`에 리네아 집의 별도 외관을, `interiors/{linea,home,chief,clinic,hall,store,smithy,inn}.png`에 리네아 집·시온 집·촌장 집·치유소·수련소·잡화점·대장간·여관 내부 원화를 추가했습니다. 건물별 구조와 가구, 색감을 구분했습니다. 크기와 디자인, 게임 적용 전 필요한 사항은 `interiors/README.md`를 참고하세요. 총 9장(외관 1장·실내 8장)은 원화 제작이며 현재 게임의 배치나 실내 이미지를 교체하지 않았습니다.
