# 로웬 마을 건물 원화 · 외관 1장과 실내 8장

기존 `residential.png`의 목재·석재·회벽 화풍을 참고해 이미지 생성 도구로 제작했습니다. 리네아 집은 기존 네 건물과 구분되는 낮은 청록색 지붕과 현관을 가진 별도 외관입니다. 내부는 외관과 같은 재료·색감을 참고한 독립적인 공간 디자인입니다.

| 파일 | 공간 | 크기 | 형식 |
| --- | --- | --- | --- |
| `../linea-house.png` | 리네아 집 외관 | 1536 × 1024 | RGBA |
| `linea.png` | 리네아 집 내부 | 1028 × 686 | RGB |
| `home.png` | 시온 집 내부 | 1134 × 756 | RGB |
| `chief.png` | 촌장 집 내부 | 1280 × 640 | RGB |
| `clinic.png` | 치유소 내부 | 1432 × 955 | RGB |

- 리네아 집: 창가 꽃병, 창문을 고정하는 매듭 끈, 일지 책상과 침대. 건강한 꽃이 있는 평온한 낮 모습이며 습격·소멸 이후의 변형은 별도 제작 대상입니다. 매듭은 스토리 소품의 시각 초안이며 이 크기의 원화에서 정확한 감기 방식까지 확정하지 않습니다.
- 시온 집: 세레나·시온·시아의 세 잠자리와 부엌, 생활 가구.
- 촌장 집: 기록·서신 보관과 회의, 남청색 직물과 호두나무 가구.
- 치유소: 두 환자 침대, 밝은 목재·상아색 회벽·약초·온실.

외관은 투명 RGBA PNG이고, 실내 8장은 가구와 조명이 합쳐진 불투명 배경 원화입니다. 현재 게임에는 실내 8곳 모두 WebP 실행본을 적용했습니다. 원화에서 측정한 바닥·가구·문 좌표는 `src/world/interiors.ts`의 `INTERIOR_ART`에 있으며, 가로세로 비율을 유지해 월드로 변환합니다. 시온 집의 침대도 원화처럼 세 개의 충돌 영역을 사용합니다. 카운터와 가구는 원화에서 윤곽을 잘라 투명한 전경으로 그리고, 앞벽은 바닥 경계 아래에 따로 그립니다. 촌장 집과 치유소의 닫힌 문은 아치 앞에서 출입합니다.

## 2차 실내 4장

기존 `../residential.png`와 `../commerce.png`를 시설의 외형·재료 기준으로, `home.png`를 실내 화풍·카메라 기준으로 이미지 생성 도구로 제작했습니다.

- 수련소: 넓은 올리브색 매트, 세 허수아비와 연습 무기 거치대, 벤치·물통.
- 잡화점: 청록색 직물, 생활용품·물약·포목 선반, 장부·저울이 놓인 판매대.
- 대장간: 거친 석재 벽과 바닥, 화로·모루·담금질 수조·숫돌·작업대.
- 여관: 벽난로와 식탁, 접수대·술통·식기와 위층 객실을 암시하는 계단. 1층 공용 공간 한 장이며 별도 객실 이미지는 포함하지 않습니다.

네 공간 모두 인물 없이 중앙 이동 통로를 비워 두고, 아래쪽 중앙 출입구와 기존 실내 원화의 절개 구도를 유지했습니다. 건물의 구조와 소품은 시각적 디자인이며 스토리의 새 사건이나 기능을 확정하지 않습니다.

예정했던 리네아 집 외관 1장과 실내 8장, 총 9장 원화가 준비됐습니다. 기존 아트는 유지했으며 생성 원본은 `/workspace/generated_images/`에 보존했습니다.

## 실행용 이미지와 재생성

저장소 루트에서 `python3 tools/build_map_art.py`를 실행하면 PNG와 같은 픽셀 크기의 WebP를 생성합니다. Pillow가 필요합니다. `INTERIOR_ART`의 측정 좌표로 원화의 정수 픽셀 경계를 찾아 자릅니다. 잘라낸 조각은 원본 픽셀 크기로 배치합니다.

`src/world/mapArt.ts`에서 입장하는 실내의 실행본만 로드하고, 방문한 텍스처는 재사용합니다. 실내의 예전 코드 가구는 중복해서 그리지 않습니다. 확인할 때는 각 집 출입, 가구 충돌, 카운터 앞 대화, 작은 화면의 문·카메라 경계를 함께 검사하세요. 원본은 제작 자료이며 실행 중 직접 내려받지 않습니다.

## 실내 크기와 가구 객체

`INTERIOR_ART`의 가구마다 고유 ID, 바닥 점유 영역, 원화 표시 영역을 정의합니다. `interiorBackgroundPieces()`가 원화에서 가구 영역을 제외한 벽·바닥 조각을 나누고, `drawInterior()`가 동일한 텍스처를 공유하는 독립 이미지 객체로 가구를 조립합니다. 원화에서 잘라낸 바닥과 가구 조각으로 캐릭터 뒤의 그림을 복원합니다. 캐릭터 앞에 올 수 있는 가구와 카운터는 `interiorLayers.ts`의 윤곽을 따라 만든 투명 레이어로만 캐릭터를 가립니다. 탁자 위 작은 식기 등은 해당 가구 객체에 포함됩니다. 원본 PNG와 실행용 WebP를 다시 그리거나 추가 다운로드하지 않습니다.

가구의 충돌은 그림과 같은 데이터에서 생성하고 작은 여유를 둡니다. 창문·벽은 바닥 다각형 밖에 두고, 여관 계단·치유소 온실·리네아 집 창가 등은 출입 금지 영역도 사용합니다. 큰 이동도 `WalkArea.move()`의 단계별 검사로 막습니다. 침대 휴식 위치와 치유사 위치는 새 실내 비율에 맞춰 조정했습니다.

검증: `npm test`, `npm run build`, 브라우저 검사의 '여덟 실내의 가구', 건물 출입·상점 대화 시나리오. 가구 충돌뿐 아니라 입구에서 침대·상인 앞으로 이어지는 통로도 검사합니다.
