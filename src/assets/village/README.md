# 시작 마을 아트

참고 화면의 잔디·흙길·자연 소품 분위기를 바탕으로 이미지 생성 도구로 제작한 독립 아트입니다. 기존 주인공의 SD 스타일에 맞춰 밝은 낮의 목조 마을로 구성했습니다.

- `ground.png`: 잔디, 흙길, 평평한 잔돌과 풀꽃만 포함한 1536×1024 지면입니다. 게임에서 2400×1600으로 표시합니다.
- `home.png`: 기와 지붕, 목재·흙벽, 돌기단과 현관이 있는 주인공의 집 외관입니다. 투명 배경이며 간판 글자는 코드에서 표시합니다.
- `props.png`: 4열 × 2행의 투명 소품 시트입니다. 위 행은 활엽수·소나무·큰 바위·관목, 아래 행은 작은 바위·풀꽃·이정표·그루터기입니다.
- `frames.json`: 원본 픽셀은 유지하고 실제 그림 영역만 측정한 좌표입니다.

```bash
python3 tools/build_village_frames.py
npm run build
npm test
npm run test:browser
```

배치와 이동 영역은 `src/world/villageLayout.ts`에서 함께 관리합니다. 지붕·수관 전체를 장애물로 막지 않고, 집의 벽과 줄기·바위의 바닥 접점을 사용합니다. 집 앞 시작점과 현관 앞은 비워 두며, 충돌이 없는 작은 돌·꽃은 장식으로 배치합니다. 이동은 짧은 구간으로 나누어 회피 중 장애물 관통을 방지합니다.

실제 화면에서 집 앞 시작, 집을 돌아가는 길, 나무 앞뒤 겹침, 흙길과 바위 사이 이동, 화면 비율과 카메라 가장자리에서 캐릭터·이름표·조작 버튼이 잘리지 않는지 확인합니다. 집 내부와 출입 기능은 현재 아트 범위에 포함하지 않습니다.
