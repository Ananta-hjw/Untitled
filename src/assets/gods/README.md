# 여섯 신 디자인과 권능 장면

`docs/story.md`의 여섯 권능을 바탕으로 제작한 전신 컨셉 이미지입니다. 모두 1024 × 1536 투명 배경 RGBA PNG이며, 머리 장식부터 발까지 보이는 단일 인물 디자인입니다. 봉인으로 쇠약해진 현재의 모습을 시각화했습니다.

| 파일 | 신 | 디자인 |
| --- | --- | --- |
| `aurea/fullbody.png` | 창조신 아우레아 | 성숙한 여성형. 금빛 머리카락이 뿌리와 가지로 이어지고 상아색 꽃잎 의복이 펼쳐집니다. 생명력과 포용적인 미소에 마른 가지와 깨진 옷 가장자리를 대비했습니다. |
| `serdin/fullbody.png` | 질서신 세르딘 | 중성적인 성인형. 은백색·남청색 의복과 직선 장식, 좌우 대칭과 무표정으로 완벽한 질서를 표현했습니다. 가슴의 작은 균열이 대칭을 깨뜨립니다. |
| `barden/fullbody.png` | 수호신 바르덴 | 거대한 장년 남성형. 성벽 같은 회백색·청동 갑주, 넓은 이끼색 망토와 감싸는 손으로 수호를 표현했습니다. 내부에서 번진 듯한 균열과 마모가 남아 있습니다. |
| `drakan/fullbody.png` | 파괴신 드라칸 | 강인한 성인 여성형. 흑철과 적동색 갑주, 광물 같은 육체와 균열 사이의 열기로 파괴를 표현했습니다. 분노보다 결연함을 강조하고 일부 장갑의 손상을 남겼습니다. |
| `zaires/fullbody.png` | 혼돈신 자이레스 | 나이와 성별을 단정하기 어려운 성인형. 보라·청록빛 변색 재질, 비대칭 장식과 어긋난 고리, 서로 다른 방향의 흐름으로 혼돈을 표현했습니다. 일부 고리가 끊겨 있습니다. |
| `neirun/fullbody.png` | 소멸신 네이룬 | 가느다란 중성적 성인형. 먹빛·진주 회색·빛바랜 보라색, 고요한 얼굴과 흐릿해지는 몸·옷의 경계로 소멸과 안식을 함께 표현했습니다. |

## 공통 기준

이오르하에게서 나뉜 존재라는 인상을 위해 원형을 나눈 장식, 빛과 어둠을 함께 품은 눈의 세부, 피부·금속·천의 경계가 모호한 재질을 공통 모티프로 삼았습니다. 권능마다 형태와 비율을 다르게 적용했습니다. 신의 겉모습은 인간이 이해할 수 있는 형상이라는 디자인 제안이며 실제 성별·나이의 확정을 의미하지 않습니다.

아우레아는 기존 시온의 `../hero/dialogue/neutral.png`를 화풍 참고로 이미지 생성 도구로 제작했습니다. 나머지 다섯 신은 아우레아의 이미지로 화풍과 재질의 일관성을 맞췄습니다. 기준 캐릭터 원본 시트 출처는 `../hero/academy/README.md`를 참조하세요.

## 대화용 일러스트

각 신의 폴더에 `dialogue.png`를 추가했습니다. 해당 신의 `fullbody.png`를 참고해 이미지 생성 도구로 제작한 별도 구도이며, 모두 1024 × 1536 투명 배경 RGBA PNG입니다. 머리 장식부터 무릎 위 부근까지 담고, 전신보다 얼굴과 손동작을 크게 보여주도록 구성했습니다.

- 아우레아: 모성적인 미소와 새싹을 든 손, 마른 가지와 의복의 균열을 유지했습니다.
- 세르딘: 정면 대칭과 무표정, 손바닥을 펼친 자세와 가슴의 균열을 유지했습니다.
- 바르덴: 거대한 갑주의 무게감을 유지하면서 손을 몸 가까이 모아 보호하는 자세로 조정했습니다.
- 드라칸: 결연한 시선과 흑철·적동색 갑주, 균열 사이의 열기를 유지했습니다.
- 자이레스: 속내를 알 수 없는 미소와 비대칭 장식, 어긋난 고리를 유지했습니다.
- 네이룬: 고요한 얼굴과 열린 손, 흐릿해지는 머리카락과 의복의 가장자리를 유지했습니다.

## 권능을 드러내는 장면

각 신의 폴더에 `power_scene.png`가 있습니다. 해당 신의 `fullbody.png`를 참고해 이미지 생성 도구로 제작한 1536 × 1024 가로형 불투명 PNG입니다. 인물뿐 아니라 배경과 권능의 작용을 함께 담은 독립 장면입니다.

| 신 | 연출 |
| --- | --- |
| 아우레아 | 황량한 땅에서 금빛 씨앗과 뿌리를 통해 숲과 생명이 새로 태어납니다. 생명의 아름다움과 끝없이 번지는 성장의 위압감을 함께 표현했습니다. |
| 세르딘 | 무너진 기둥과 부유하는 파편이 격자와 정확한 간격 아래 정렬되고, 물방울과 공간의 움직임이 멈춥니다. 냉정한 아름다움과 숨 막히는 질서를 표현했습니다. |
| 바르덴 | 거대한 충격을 여러 겹의 성벽 같은 방벽으로 받아내고, 안쪽 숲은 고요하게 지킵니다. 방벽이 안쪽을 감싸는 폐쇄적인 느낌도 남겼습니다. |
| 드라칸 | 손이 닿은 구조물에서 균열이 번지고 성벽과 사슬이 물리적으로 부서집니다. 잔해와 먼지가 남도록 해 소멸과 구분했습니다. |
| 자이레스 | 같은 다리와 탑의 여러 가능성이 겹치며, 길과 중력이 뒤틀리고 계절과 시간이 다른 공간이 맞닿습니다. |
| 네이룬 | 고대 성소와 물에 비친 모습이 폭발이나 잔해 없이 윤곽부터 조용히 사라집니다. 공포와 마지막 안식을 함께 표현했습니다. |

이 장면들은 권능을 보여주는 상징적인 연출 컨셉이며, 본편에서 신이 이미 봉인을 풀고 활동한다는 설정이나 특정 사건·지명·기술의 확정이 아닙니다. 바르덴 장면은 추가로 생성된 팔을 이미지 편집 도구로 제거해 두 팔의 자세로 수정했습니다.

게임 화면·전투·대화 UI에는 아직 연결하지 않았습니다. SD와 애니메이션 시트는 포함하지 않습니다. 문양과 외형은 컨셉 디자인이며 봉인 조건이나 성물 설정을 변경하지 않습니다.
