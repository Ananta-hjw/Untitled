# 사령관 대화용 일러스트

`docs/story.md`의 사령관 설정을 바탕으로 이미지 생성 도구로 제작한 무릎 위 대화용 이미지입니다. 모두 1024 × 1536 투명 RGBA PNG이며 게임 대화창에는 아직 연결하지 않았습니다.

사령관은 키엘·로엘을 각각 세어 총 9명입니다. 최신 노크투르·오르웬·루미에라 3명은 유지하고, 나머지 6명을 추가했습니다. 전원 신이 빚은 권속이며 인간 계승자와 구분합니다. 인간처럼 보이는 형상도 인간 출신이라는 의미는 아닙니다.

신들과 외형이 지나치게 비슷했던 초안을 사용자 요청으로 전면 재디자인했습니다. 각자의 역할과 핵심 설정을 유지하면서 얼굴·머리·복장·색감·소품·자세를 크게 바꿨습니다.

## 설정과 외형의 연결

- 칸토르는 카이렌이 평생 따른 법을 만든 사령관이므로, 전투 자세보다 법전을 근거로 판결하는 자세를 우선했습니다.
- 하겔의 충직한 보호자 인상은 브람을 시험하고 권능 사용을 유도하는 목적과 함께 읽혀야 합니다. 방패의 크기가 현재 사령관 간 전투력 순위를 뜻하지는 않습니다.
- 볼가르와 에스라는 같은 파괴를 힘으로 강요하는 길과 공감으로 설득하는 길로 나눕니다. 에스라의 차분한 얼굴을 악역의 분노로 바꾸지 않았습니다.
- 키엘·로엘은 한 장에 합치지 않고 각자 대화용 파일을 가집니다. 가면·검은 머리·청록 외투·연결 고리와 소매 무늬를 공유하며, 표정·안감·손짓으로 구분합니다.
- 루미에라의 맹목적인 귀환 의지, 오르웬의 인간을 택한 쇠약함, 노크투르의 예의 바른 압박은 앞선 최신 디자인의 기준을 유지합니다.

최초 신들의 초상 대신 `../hero/dialogue/neutral.png`를 인물 일러스트의 표현 참고로 삼았습니다. 시각적 기준은 인상이 읽히는 게임 캐릭터이며, 세 인물끼리도 실루엣과 소품을 구분했습니다.

추가 6명은 최신 노크투르 이미지를 화풍 참고로만 사용했습니다. 얼굴·모자·베일·예복을 복제하지 않고 각각의 문서상 모습을 우선했습니다.

노크투르의 검은 베일, 오르웬의 낡은 갑주와 노쇠함, 루미에라의 빛나는 한 쌍의 날개는 스토리 설정을 유지합니다. 세부 외형과 겉보기 나이는 이번 디자인 제안이며 실제 나이·출생·종족 설정을 새로 확정하지 않습니다. 이전 초안은 생성 원본과 앞서 제공한 다운로드 묶음에 남아 있으며, 이 폴더의 `dialogue.png`가 최신 디자인입니다.
