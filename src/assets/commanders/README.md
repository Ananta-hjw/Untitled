# 사령관 일러스트

`docs/story.md`의 사령관 설정을 바탕으로 이미지 생성 도구로 제작한 무릎 위 대화용 이미지입니다. 모두 1024 × 1536 투명 RGBA PNG이며 게임 대화창에는 아직 연결하지 않았습니다.

사령관은 키엘·로엘을 각각 세어 총 9명입니다. 최신 노크투르·오르웬·루미에라 3명은 유지하고, 나머지 6명을 추가했습니다. 전원 신이 빚은 권속이며 인간 계승자와 구분합니다. 인간처럼 보이는 형상도 인간 출신이라는 의미는 아닙니다.

신들과 외형이 지나치게 비슷했던 초안을 사용자 요청으로 전면 재디자인했습니다. 각자의 역할과 핵심 설정을 유지하면서 얼굴·머리·복장·색감·소품·자세를 크게 바꿨습니다.

## 설정과 외형의 연결

- 칸토르는 카이렌이 평생 따른 법을 만든 사령관입니다. 최신 일러스트는 사용자 요청으로 책을 들지 않으며, 정돈된 갑주와 엄정한 자세로 성격을 표현합니다. 스토리 문서의 설정 자체를 변경한 것은 아닙니다.
- 하겔의 충직한 보호자 인상은 브람을 시험하고 권능 사용을 유도하는 목적과 함께 읽혀야 합니다. 방패의 크기가 현재 사령관 간 전투력 순위를 뜻하지는 않습니다.
- 볼가르와 에스라는 같은 파괴를 힘으로 강요하는 길과 공감으로 설득하는 길로 나눕니다. 에스라의 차분한 얼굴을 악역의 분노로 바꾸지 않았습니다.
- 키엘·로엘은 한 장에 합치지 않고 각자 대화용 파일을 가집니다. 가면·검은 머리·청록 외투·연결 고리와 소매 무늬를 공유하며, 표정·안감·손짓으로 구분합니다.
- 루미에라의 맹목적인 귀환 의지, 오르웬의 인간을 택한 쇠약함, 노크투르의 예의 바른 압박은 앞선 최신 디자인의 기준을 유지합니다.

최초 신들의 초상 대신 `../hero/dialogue/neutral.png`를 인물 일러스트의 표현 참고로 삼았습니다. 시각적 기준은 인상이 읽히는 게임 캐릭터이며, 세 인물끼리도 실루엣과 소품을 구분했습니다.

추가 6명은 최신 노크투르 이미지를 화풍 참고로만 사용했습니다. 얼굴·모자·베일·예복을 복제하지 않고 각각의 문서상 모습을 우선했습니다.

노크투르의 검은 베일, 오르웬의 낡은 갑주와 노쇠함, 루미에라의 빛나는 한 쌍의 날개는 스토리 설정을 유지합니다. 세부 외형과 겉보기 나이는 이번 디자인 제안이며 실제 나이·출생·종족 설정을 새로 확정하지 않습니다. 이전 초안은 생성 원본과 앞서 제공한 다운로드 묶음에 남아 있으며, 이 폴더의 `dialogue.png`가 최신 디자인입니다.

## SD 기본 자세

9명 모두 최신 `dialogue.png`를 바탕으로 제작한 전신 SD 이미지 `각 인물 폴더/sd_idle.png`를 가집니다. 모두 1254 × 1254 투명 RGBA PNG이며, 입을 다문 기본 표정으로 제작했습니다. 키엘·로엘은 가면의 웃는 선과 우는 선을 유지합니다.

- 오르웬의 노쇠함, 하겔의 거구와 등 방패, 볼가르의 뿔·비늘·망치, 에스라의 석상 균열과 설계도를 구분했습니다.
- 루미에라의 한 쌍의 유리 깃털 날개, 노크투르의 베일과 모래시계, 쌍둥이의 가면과 서로 다른 안감·소품을 유지했습니다.
- 칸토르는 최신 대화용 이미지와 동일하게 책 없이 빈손으로 서 있습니다.

정지 이미지 외에 아래 4명의 이동 시트를 추가했습니다. 공격 애니메이션, 모바일용 축소본, 게임 내 배치는 아직 포함하지 않습니다. 생성 원본은 `/workspace/generated_images/`에 보존했습니다.


## 1차 이동 시트 · 4명

노크투르·오르웬·루미에라·칸토르의 최신 `sd_idle.png`를 기준으로 이미지 생성 도구로 제작했습니다. 기존 대화용 이미지와 정지 원본은 보존합니다.

- 노크투르: 검은 모자와 베일·청록 테두리 예복·모래시계를 유지한 절제된 걸음.
- 오르웬: 벗겨진 이마와 흰 수염·낡은 갑주·주황 망토를 유지하고, 지팡이를 짚으며 투구를 안고 걷는 노기사.
- 루미에라: 붉은 단발·남청색 성직복·유리 깃털 날개를 유지하고, 성물함을 양손으로 든 지상 보행.
- 칸토르: 폐쇄형 투구·거대한 갑주·적갈색 천을 유지한 무거운 걸음. 책이나 무기를 추가하지 않았습니다.

각 폴더의 `walk_cardinal.png`는 위에서부터 아래·왼쪽·오른쪽·위, `walk_diagonal.png`는 왼쪽 아래·오른쪽 아래·왼쪽 위·오른쪽 위입니다. 모두 투명 RGBA PNG이며 4열 × 4행입니다. 각 행은 0열 대기, 1~3열 걷기 포즈입니다. 인물당 32프레임, 4명 총 128프레임을 준비했습니다. 권장 걷기 순서는 초당 8프레임으로 `[1, 2, 3, 2]`입니다.

기본 시트는 모두 1254 × 1254입니다. 대각선은 노크투르·오르웬·칸토르 1254 × 1254, 루미에라 1241 × 1267이며, 정확한 크기·프레임 영역·원점·방향별 배율은 `walk_frames.json`에 기록했습니다. 자동 측정은 원본 픽셀을 변경하지 않습니다. 알파 128 기준으로 모든 프레임이 자기 칸 안에 들어가는지 검사했습니다.

```bash
python3 tools/build_npc_frames.py --asset-group commanders
npm run dev
```

`/tools/npc-walk-preview.html?group=commanders`에서 4명의 8방향 대기·걷기와 재생 속도를 확인할 수 있습니다. 실제 이동 경로, 발 미끄러짐과 깊이 순서는 게임에 연결할 때 추가로 검수해야 합니다. 이번 작업은 이동 원화·좌표·미리보기까지이며 게임에는 아직 연결하지 않았습니다.

남은 사령관 이동 시트는 하겔·볼가르·에스라·키엘·로엘 5명입니다.
