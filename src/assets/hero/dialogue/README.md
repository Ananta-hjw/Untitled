# 주인공 대화용 일러스트

- `neutral.png`: 1024 × 1536, 투명 배경 RGBA PNG. 머리부터 무릎까지 보이는 기본 대화 표정입니다.
- 현재 캐릭터 시트 `../academy/player_walk.png`를 참고해 이미지 생성 도구로 제작했습니다. 원본 시트의 출처는 `../academy/README.md`를 참조하세요.
- 검은 장발, 붉은 코트, 금속 어깨 보호구, 푸른 가슴 장식과 등에 멘 검·칼집을 반영했습니다.
- 대화 화면에 사용할 독립 이미지이며, 게임 내 캐릭터 시트와 애니메이션은 변경하지 않았습니다. 대화 UI 연결은 별도 구현이 필요합니다.
- `neutral-768.png`: 게임 대화창에서 실제로 쓰는 축소본입니다. `neutral.png`의 투명 여백을 잘라 내고 높이 768px로 줄였습니다(화면에는 약 360px로 표시). 원본을 바꾸면 이 파일도 같은 방식으로 다시 만듭니다.
