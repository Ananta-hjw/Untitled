# 오른쪽 측면 6프레임 공격 원화

`attack-side-source.png`는 기존 `player_combat.png`의 왼쪽 위 자세를 캐릭터 기준으로 이미지 생성 도구로 제작한 투명 RGBA 원본입니다. 크기는 1536×1024이며 512×512 셀을 3열×2행으로 배치했습니다.

왼쪽 위부터 준비 → 예비 동작 → 최대 들어 올림 → 타격 → 내려 베기 마무리 → 복귀 순서입니다. 한 손으로 검을 잡는 오른쪽 측면 동작이며 이펙트·배경을 포함하지 않습니다.

요청한 발 기준선(셀 위에서 450px)과 프레임별 검 길이는 정확히 맞지 않습니다. 런타임 적용 전 발·손·검끝 기준점을 측정하고 정렬 및 동작 보정이 필요합니다. 현재 게임의 기존 공격 시트·판정·타이밍에는 연결하지 않은 제작 원본입니다.

`attack-side-sword-removed.png`는 손에 든 검을 제거한 편집본입니다. 원본과 동일한 1536×1024 투명 RGBA 시트에 6프레임을 배치했으며, 검을 쥔 손의 위치와 등 뒤 칼집을 유지합니다.
