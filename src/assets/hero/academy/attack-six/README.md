# 오른쪽 측면 6프레임 공격 원화

`attack-side-source.png`는 기존 `player_combat.png`의 왼쪽 위 자세를 캐릭터 기준으로 이미지 생성 도구로 제작한 투명 RGBA 원본입니다. 크기는 1536×1024이며 512×512 셀을 3열×2행으로 배치했습니다.

왼쪽 위부터 준비 → 예비 동작 → 최대 들어 올림 → 타격 → 내려 베기 마무리 → 복귀 순서입니다. 한 손으로 검을 잡는 오른쪽 측면 동작이며 이펙트·배경을 포함하지 않습니다.

요청한 발 기준선(셀 위에서 450px)과 프레임별 검 길이는 정확히 맞지 않습니다. 런타임 적용 전 발·손·검끝 기준점을 측정하고 정렬 및 동작 보정이 필요합니다.

`attack-side-sword-removed.png`는 손에 든 검을 제거한 편집본입니다. 원본과 동일한 1536×1024 투명 RGBA 시트에 6프레임을 배치했으며, 검을 쥔 손의 위치와 등 뒤 칼집을 유지합니다.

## 게임 연결

`python3 tools/build_attack_six.py`가 원화를 고치지 않고 칼을 지운 편집본으로 `attack-side.webp`와 `attack-side_frames.json`을 만든다.
거의 투명한 번짐(알파 24 미만)을 지우고, 6칸을 같은 배율(몸 높이 310 → 304px)로 줄인다.
발 기준점은 디딘 앞발 발끝에서 68px 뒤라 앞발은 고정되고 뒷발만 벌어진다.
칸마다 칼이 그려진 원본에서 눈으로 잰 코등이·칼끝 좌표가 스크립트의 `FRAMES`에 있다. 두 그림의 몸 위치가 픽셀 단위로 같아 그대로 쓴다.

게임은 좌우 1타에 이 6자세를 쓴다(`heroFrames.ts`의 `SIDE_SIX_STARTS`: 0·40·110·200·280·350ms, 타격 자세 200~280ms가 명중 구간 220~275ms를 덮는다).
칼은 다른 자세처럼 장착 무기 레이어(나무검·철검)로 그린다. 잰 코등이에 무기의 코등이를, 칼끝 방향으로 칼날을 놓으며,
손잡이는 몸 뒤에 그려 주먹이 가린다. 명중 판정과 검기도 같은 칼날 좌표를 쓴다.
