# 검 막기 자세

기존 붉은 코트 주인공의 전투 원화를 참고해 이미지 생성 도구로 만든 막기 전용 자세입니다. 한 동작을 측면·앞 대각선·뒤 대각선 세 시점으로 표시하며, 왼쪽은 몸과 검을 함께 반전합니다. 머리와 발은 회전시키지 않습니다.

- `guide.png`: 3열 원화. 청록 점은 낮춘 손잡이 손, 자홍 점은 위쪽 손바닥 중심을 표시합니다. 검은 수직에서 12도 기울이고, 손바닥 높이에서 검과 만나는 위치를 별도로 측정합니다. 노란 점은 방향 참고용입니다.
- `source.png`: 표시점을 제거한 몸 원화. 검은 장착 장비에 따라 별도 레이어로 표시합니다.
- `frames.json`: 몸 영역, 발 원점, 주먹·손바닥·가드·검끝 좌표와 손바닥 가림 영역입니다.
- `bodies.webp`: 실제 실행 중 불러오는 단일 압축 아틀라스입니다. 원본 PNG는 실행 중 읽지 않습니다.

재생성:

```bash
python3 tools/build_guard_frames.py
```

Pillow는 좌표 측정에만 사용하고, ImageMagick이 자르기·크기 변경·WebP 압축을 수행합니다. 몸 높이는 기존 주인공과 같은 304 로컬 픽셀, 검 길이는 150, 손에서 가드까지는 12입니다. 검을 드는 첫 70ms 동안 손을 축으로 약 1도만 정렬하며, 검날과 손잡이는 같은 각도로 움직입니다. 위쪽 손바닥은 검보다 뒤에 표시해 칼날이 손에 가려지지 않도록 합니다.

`HeroSprite.setGuarding()`으로 자세를 켜고 끕니다. 공격·회피는 이 자세를 즉시 해제하며, 막기가 끝나면 기존 대기·걷기로 돌아갑니다. `GameScene.drawShield()`는 검날에만 얇은 반사광을 그리고, 패링 성공 효과도 실제 검날 가운데에서 발생합니다.

변경 후 여섯 방향의 파지, 철검·나무검 교체와 무기 해제, 공격 취소, 막기 종료·회피 복귀를 확인합니다.

표시 순서는 손잡이 → 몸 → 받치는 손바닥 → 검날입니다. 반사광도 이 영역을 건너뛰므로 빛이 손을 관통하지 않습니다. 손잡이는 한 손에 맞게 30 로컬 픽셀로 표시하며, 검날 길이와 독립적으로 조절합니다.

왼쪽 위·오른쪽 위에는 별도 전신 자세 `guard-up-back`을 사용합니다. `back-guide.png`의 청록 점은 주먹 바깥쪽 관절, 자홍 점은 받치는 손등, 노란 점은 손잡이 팔의 낮춘 팔꿈치입니다. `back-source.png`는 표시점을 제거한 원화입니다. 손잡이는 청록 점에서 몸 안쪽으로 7 로컬 픽셀 들어간 주먹 내부에 맞춥니다.

두 팔꿈치를 내려 팔을 몸 가까이 두고, 받치는 팔뚝이 손으로 완만하게 올라가도록 했습니다. 손등은 긴 손가락 네 개와 엄지 하나로 구분하며 검날보다 앞에 표시합니다. 오른쪽 위의 엄지는 화면 오른쪽, 왼쪽 위의 엄지는 화면 왼쪽입니다. 나머지 방향은 기존 원화를 사용합니다.
