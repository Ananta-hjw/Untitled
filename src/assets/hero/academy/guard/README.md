# 검 막기 자세

기존 `unarmed/player_walk.png`를 이미지 생성 도구의 기준으로 사용해, 같은 큰 머리·작은 몸 비율과 붉은 코트·머리 모양을 유지한 막기 자세입니다. 오른발을 뒤로 빼고 앞쪽 왼무릎을 굽혀 버티는 자세입니다. 오른손은 허리 앞의 손잡이를 잡고, 왼손은 몸에서 조금 더 떨어진 칼날 중간을 받칩니다. 뒤로 뺀 발이 바뀌어도 몸이 옆으로 튀지 않도록 발 원점은 `FOOT_X`로 고정합니다. 후면의 손잡이 손은 몸 앞에 가려지고, 왼손은 몸 바깥에서 칼날을 받칩니다.

5열 원화와 정면 전용 원화 모두 대기 이미지에 맞춰 색감을 보정했습니다. 머리카락의 밝은 구릿빛을 줄이고 차분한 짙은 갈색, 깊은 붉은 코트, 어두운 가죽색으로 맞췄습니다. 자세와 손·검 기준 좌표는 유지하며, 좌우 반전을 포함한 8방향의 대기/막기 모습을 함께 비교합니다.

- `poses-source.png`: 투명 배경 5열 원화. 순서: 오른쪽 측면, 앞 대각선, 뒤 대각선, 정면(아래), 후면(위).
- `side.png`, `down.png`, `up-back.png`, `front.png`, `back.png`: 원화에서 분리하고 높이를 맞춘 방향별 파일. 뒤 대각선은 오른쪽 위를 향하도록 반전합니다.
- `front-source.png`: 정면 전용 원화. 오른손 주먹과 손목을 화면 오른쪽으로 틀어 기울어진 손잡이를 감싸도록 수정했습니다. 정면은 5열 원화 대신 이 파일에서 생성합니다.
- `bodies.webp`: 게임이 읽는 5자세 아틀라스.
- `frames.json`: 발 원점, 주먹·받치는 손·검 좌표와 표시 순서 정보.
- 기존 `source.png`, `guide.png`, `back-source.png`, `back-guide.png`는 이전 원화 보관용이며 현재 생성 과정에서는 읽지 않습니다.

재생성:

```bash
python3 tools/build_guard_frames.py
```

Python/Pillow는 영역과 발 위치를 측정하며 ImageMagick이 이미지 분리·반전·축소·압축을 수행합니다. 오른손 주먹 위치는 `ANCHORS`, 실제 왼손 손바닥 위치는 `PALMS`에 있습니다. 칼은 수직 기준 50도로 기울이고, 칼날 중간(가드에서 75픽셀)을 받치는 접점으로 사용합니다. 정면 후면에서는 기울기의 좌우를 바꿔 왼손 쪽으로 검을 세웁니다. 원화를 바꾸면 손 위치도 다시 측정합니다. 몸 높이는 기존 걷기와 같은 304 로컬 픽셀이고, 검 길이는 150, 손에서 가드까지는 12입니다.

`guardFrame()`은 정면을 `guard-front`, 후면을 `guard-back`으로 선택합니다. 대각선 그림으로 대체하거나 마지막 좌우 방향에 따라 정면·후면을 반전하지 않습니다. 왼쪽 측면·대각선만 몸과 검을 함께 반전합니다.

앞쪽은 손잡이 → 몸 → 받치는 손 → 검날 순서입니다. 뒤 대각선과 후면은 `weaponBehind`를 사용해 검날·손잡이를 몸 뒤에 놓고 별도 손 레이어를 숨깁니다. 검은 몸 밖으로 나온 부분만 보이며 반사광도 캐릭터 뒤에 그립니다. 장착 무기에 따라 철검·나무검이 바뀌고, 무기를 해제하면 무기와 손 덮개를 숨깁니다.

`HeroSprite.setGuarding()`으로 켜고 끕니다. 공격·회피는 막기 자세를 해제하고 종료 시 기존 대기·걷기로 돌아갑니다. 변경 후 8방향, 정면·후면 전환, 무기 교체·해제, 공격 취소와 회피 복귀를 확인합니다.

막기 시작 후 약 110ms 동안 검을 들어 올려 정렬하고, 180ms 안에 발을 축으로 몸을 기울여 버틴 뒤 안정됩니다. 작은 호흡 움직임은 게임 시간으로 진행되므로 일시정지·히트스톱과 함께 멈춥니다. `src/entities/guardMotion.ts`와 `HERO_GUARD_MOTION`에서 조정하며, 몸과 검·손 레이어는 같은 회전 축을 공유합니다. 기본 검 각도는 50도이고, 몸의 작은 기울기에 따라 화면 각도는 조금 달라집니다. 공격·회피·막기 종료 시 기울기는 즉시 초기화합니다.
