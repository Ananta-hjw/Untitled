# 위·아래 회피

`cardinal-source.png`는 기존 무장 해제 정면 대기·회피 몸 그림을 참조해 이미지 생성 도구로 제작한 투명 4열 × 2행 원본입니다. 아래쪽 정면과 위쪽 뒷모습을 각각 준비 → 낮은 돌진 → 발 모으기 → 마무리 네 자세로 구성했습니다. 좌우·대각선은 기존 회피 그림을 사용합니다.

`python3 tools/build_hero_dodge.py`로 `cardinal.webp`와 `frames.json`을 재생성합니다. 원본을 보존하고 모든 자세에 같은 배율을 적용합니다. 발 기준점과 빈 칼집 입구를 측정했으며 장착한 검의 손잡이는 기존 무기 레이어로 그립니다.

이동 입력이 없으면 `HeroSprite.lookDirection`의 8방향을 사용하고, 입력이 있으면 같은 8방향 구간으로 정렬합니다. 따라서 위·아래를 향한 입력의 작은 좌우 편차가 회피 이동을 비스듬하게 만들지 않습니다. 위·아래 전용 그림은 좌우 반전하지 않습니다. 기존 회피 시간·거리·무적·충돌·재사용 대기시간·잔상은 유지합니다.
