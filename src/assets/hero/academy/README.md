# 천무학관 캐릭터 시트

현재 게임의 주인공은 몸 애니메이션과 무기를 분리해서 표시합니다. 기존 원본 시트는 좌표 측정과 보관용으로 유지합니다.

## 원본과 추가 그림

- `player_walk.png`: `Ananta-hjw/Bi-Ryeo-Do`의 천무학관 탐색 시트를 바탕으로 붉은 코트, 갈색 가죽 장비, 금속 어깨 보호구와 등에 멘 칼집을 적용한 이미지입니다. 얼굴·머리·4방향 이동 자세는 유지합니다. 원본 기준 커밋: `59142f72f0a7156ccb3a9cdf4cccfc34c870cc40`.
- 원본 경로: `Assets/_Project/Resources/Art/Exploration/`. [원본 저장소](https://github.com/Ananta-hjw/Bi-Ryeo-Do/tree/59142f72f0a7156ccb3a9cdf4cccfc34c870cc40/Assets/_Project/Resources/Art/Exploration).
- `player_walk_atlas.json`: 수정된 의상의 외곽을 다시 측정한 프레임 영역입니다. `footX`는 시트상의 발 원점 X를 유지해, 잘라낸 영역의 폭이 달라져도 캐릭터가 좌우로 흔들리지 않도록 합니다.
- `player_walk_diagonal.png`: 같은 붉은 의상과 칼집으로 추가한 대각선 시트입니다. 위에서부터 왼쪽 아래·오른쪽 아래·왼쪽 위·오른쪽 위이며 각 행은 대기·왼발·통과·오른발의 4포즈입니다.
- `player_combat.png`: 원본 걷기 시트를 참고해 이미지 생성 도구로 추가하고 같은 붉은 코트·칼집으로 수정한 투명 시트입니다. 4열 × 4행이며 위에서부터 내려베기·올려베기·찌르기·회피입니다. 기존 저장소의 전투 그림은 사용하지 않았습니다.
- `player_attack_down.png`, `player_attack_up.png`: 대각선 앞·뒤 전용 3단 콤보 시트입니다. 각 시트는 4열 × 3행으로 내려베기·올려베기·찌르기의 준비·예비·타격·복귀를 담습니다. 오른쪽 방향을 기준으로 제작하고 왼쪽 공격은 그림과 검 좌표를 함께 반전합니다. 빈 칼집과 붉은 의상을 유지합니다.
- 걷기 그림에서는 칼집에 꽂힌 검 손잡이를 표시합니다. 검을 뽑아 든 공격·회피 그림에는 빈 칼집을 표시합니다.
- Unity 코드와 저장소 전체는 가져오지 않았습니다. 표시·방향·애니메이션 연결은 이 프로젝트의 Phaser 코드로 구현했습니다.

## 좌표와 재생

`tools/build_hero_frames.py`가 원본을 변경하지 않고 `frames.json`을 생성합니다. 걷기 좌표는 Unity의 아래쪽 원점을 Phaser의 위쪽 원점으로 변환합니다. 행 순서는 아래·왼쪽·오른쪽·위이며 각 행의 첫 칸은 대기입니다. 대각선 16프레임도 같은 순서를 사용하며, 걷기는 초당 8프레임으로 1→2→3→2를 반복합니다. 실제 이동 벡터를 45도 간격의 8방향으로 나누고, 방향 경계에 7.5도 여유를 두어 작은 입력 변화로 동작이 반복해서 초기화되지 않게 합니다. 정지하면 마지막 방향의 대기 그림을 표시합니다.

걷기 전체에 공통 배율을 적용하고 발밑을 원점으로 사용합니다. 대각선 시트는 각 행의 대기 그림에서 발 원점 X를 측정해 네 포즈에 공유하며, 발바닥의 하단을 Y 원점으로 맞춥니다. 공격 시트는 원본과 머리 크기를 맞추는 공통 배율 1.2와 프레임별 발 위치를 사용합니다. 검의 가드와 끝 좌표는 같은 파일의 `ANCHORS`, `DIAGONAL_ATTACK_ANCHORS`에 있으며, 화면상의 검과 타격·궤적 효과가 같은 기준점을 사용합니다. 왼쪽 공격은 그림과 기준점을 함께 반전합니다.

게임은 무기를 뺀 `unarmed/` 시트를 그린다. 상하좌우 걷기의 2~4번째 자세는 `unarmed` 시트에서 원본보다 최대 46px 왼쪽에 그려져 있어, 스크립트가 `UNARMED_WALK_SHIFT`만큼 영역과 발 원점을 옮기고 모든 프레임의 영역을 `unarmed` 칸의 보이는 픽셀(알파 8 이상) 전체로 넓힌다(`fit_to_unarmed`). 걷기 중 칼집 손잡이 위치(`src/entities/weaponPose.ts`의 `WALK`)도 같은 만큼 옮겼다.

시트 교체 시 이미지 크기, 영역, 발과 검의 위치를 다시 측정합니다. 걷기 의상의 외곽만 바꾼 경우 `python3 tools/build_hero_frames.py --measure-walk`로 영역을 다시 측정할 수 있으며 기존 X 원점은 유지합니다. 공격 시트의 검과 발 기준점은 `ANCHORS`, `DIAGONAL_ATTACK_ANCHORS`에서 맞춘 후 다음을 실행합니다.

```bash
python3 tools/build_hero_frames.py
npm run build
node --test tools/*.test.mjs
npm run test:browser
```

실제 화면에서 8방향 걷기와 정지, 좌우·대각선 4방향의 3단 콤보, 회피, 크기·발 위치와 잔상을 확인합니다. 생성 그림은 새 애니메이션 초안이며 원본 걷기 그림과 동작별 연결감을 함께 검토해야 합니다.

## 대각선 전투

공격 입력이 있을 때 조이스틱·키보드 방향을 우선하며, 입력이 없으면 근처 적을 평면 거리로 조준하거나 마지막 방향을 유지합니다. 전투 그림은 좌우와 대각선 4방향을 지원합니다. 각 콤보 타격의 방향은 시작할 때 고정합니다.

전진·넉백은 같은 단위 방향 벡터를 쓰고, 세로 좌표에 기존 원근 비율을 적용합니다. 발 위치로 공격 앞쪽의 회전된 레인 안에 있는지 확인한 뒤, 화면에 표시된 검날의 유효 시간 내 궤적과 적 몸의 타원을 비교합니다. 뒤쪽·옆 레인의 적은 제외하고 공격당 한 번만 피해를 줍니다. 대각선 시트의 발은 오른쪽으로 뻗은 검을 제외한 몸 영역에서 측정합니다.

브라우저 회귀 검사는 대각선 4방향 × 콤보 3단계 × 20/30/60/120fps의 48개 조건에서 앞쪽 명중·뒤/옆/먼 적 제외·전진·넉백을 확인합니다. 마지막 방향 유지·자동 조준·공격 중 방향 고정도 검사합니다.

## 분리된 무기 레이어

- `unarmed/*.png`: 이미지 생성 도구로 기존 시트의 검과 칼집 위 손잡이만 제거한 몸 원화입니다. 원본과 같은 크기·그리드이며, 기존 `frames.json`의 발·공격 기준점을 재사용합니다.
- `unarmed/*.webp`: 실제 게임이 읽는 압축된 몸 시트입니다. 원본 PNG는 실행 중 읽지 않습니다.
- `../weapons/source.png`: 따로 그린 철검·나무검 원화입니다. `weapons.webp`와 `atlas.json`은 검날·가드, 손잡이, 칼집 위 손잡이 프레임을 공유합니다.
- `src/entities/weaponPose.ts`: 걷기 32자세의 빈 칼집 입구와 기존 공격·회피의 검날 기준점을 연결합니다.
- `HeroSprite`는 손잡이→몸→검날 순서로 그립니다. 걷거나 대기할 때는 칼집 위 손잡이만 표시합니다. 무기를 해제하면 두 무기 레이어를 숨기고 검날 길이는 0이 됩니다.
- 장착 변경과 맵 재진입은 저장된 무기 ID를 적용합니다. 회피 잔상도 세 레이어를 함께 재사용하며, 검날 표시 좌표가 타격·궤적 효과의 기준점입니다.

`node tools/build_weapon_layers.mjs`로 압축 시트와 무기 아틀라스를 재생성합니다(ImageMagick 필요). 원화의 위치·크기를 바꾼 경우 몸 프레임과 손·칼집 기준점을 함께 검토해야 합니다.
