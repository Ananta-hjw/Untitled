# 로웬 마을 남쪽 들판

`overview.png`는 로웬 마을의 `../../village/rowen/overview.png`를 화풍 참고로 이미지 생성 도구로 그린 1536 × 1024 맵 컨셉 이미지입니다.

- 북쪽 마을 문에서 내려오는 흙길과 중앙의 넓은 풀밭을 연결합니다.
- 가장자리에 나무·바위·덤불을 모아 캐릭터 이동과 전투 공간을 남겼습니다.
- 서쪽 길은 숲으로, 동쪽 길은 작은 개울의 목교로 이어지는 구도입니다. 기존 게임의 출구와 새로 연결한 것은 아닙니다.
- 남서쪽 하늘색 들꽃, 동쪽 물가의 은빛 약초는 첫날 채집 퀘스트의 분위기를 참고했습니다.
- 북서쪽 낡은 석조 표식은 고대 세계의 흔적이며 태초의 눈물이나 봉인의 핵이 아닙니다.

현재는 `overview.webp`를 남쪽 들판의 배경으로 적용했습니다. 원본 PNG는 보존하고, `python3 tools/build_map_art.py`로 1536 × 1024, 품질 84 WebP 실행본을 만듭니다. 화면에는 3432 × 2288로 같은 비율로 표시합니다. 지형·전경·충돌·몬스터와 출입구도 같은 배율을 따릅니다.

- `src/world/southFieldLayout.ts`: 원화 픽셀 기준 나무줄기·바위 접점, 물가를 따라 잡은 이동 다각형과 다리 통행 영역.
- `src/world/mapArt.ts`: 입장할 때 배경을 로드하고, 나무 전경을 원화에서 한 번 잘라 투명 Canvas 텍스처로 캐시합니다. Phaser 4 WebGL에서 지원하지 않는 GeometryMask나 매 프레임 필터를 쓰지 않습니다.
- 남쪽 큰 나무의 전경 윤곽은 수관 위 풀밭을 제외하며, 가지 사이의 땅은 `holes`로 투명하게 뺍니다. 풀밭이 캐릭터 위에 덧그려져 머리나 몸이 잘려 보이지 않도록 합니다. 표시 깊이와 줄기 충돌 위치는 그대로 유지합니다.
- `src/world/maps.ts`: 예전 나무·바위 배치를 제거하고 표지판만 별도 유지합니다. 슬라임 출현 위치는 새 지형의 걸을 수 있는 곳으로 조정했습니다.

원화의 서쪽 길과 동쪽 다리는 주변 지형의 일부입니다. 실제 맵 연결은 기존처럼 북쪽 로웬 마을 출구 하나이며, 숲길·개울가로 새 출구를 만들지는 않았습니다. 이미지 교체 후에는 북쪽 왕복, 다리 위와 개울의 경계, 나무 앞뒤, 바위 충돌, 몬스터 접근 경로를 확인하세요.
