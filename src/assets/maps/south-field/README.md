# 로웬 마을 남쪽 들판

`overview.png`와 `overview.webp`는 초기 1536 × 1024 맵 원화이며 참고용으로 보존합니다.

현재 실행 배경은 `ground.webp`입니다. 이미지 생성 도구로 기존 원화에서 나무·바위·석조 표식을 제거한 `ground.png`를 만들었습니다. 흙길, 풀밭, 꽃, 개울과 다리, 북쪽 문을 지면에 남겼습니다. 새로운 신화적 표식이나 출구를 추가하지 않았습니다.

- 현재 지면은 3432 × 2288 픽셀이며 월드에 1:1로 표시합니다. `python3 tools/build_map_art.py`로 같은 크기의 WebP 실행본을 만듭니다.
- `src/world/southFieldLayout.ts`의 `FIELD_PROPS`에 나무·돌의 발 위치, 그림 너비, 충돌 접점을 함께 정의합니다. 렌더링과 충돌이 같은 월드 픽셀 좌표를 사용합니다.
- 객체 이미지는 기존 `src/assets/village/props.png` 아틀라스의 나무·바위를 공유합니다. `buildMap()`이 독립 Image 객체로 만들고 발의 y좌표로 캐릭터와 앞뒤 순서를 정합니다. 배경을 다시 잘라 덧그리는 전경 마스크는 사용하지 않습니다.
- `mapObstacles()`는 각 소품의 `footprint`에서 충돌을 만듭니다. 그림과 따로 관리하는 수동 장애물 목록은 없습니다. 나무는 줄기·뿌리, 바위는 바닥 접점을 막고, 수관 뒤로 걸으면 캐릭터가 자연스럽게 가려집니다.
- 물가 이동 다각형과 다리 통행 영역은 같은 파일에 있습니다. 실제 연결은 북쪽 로웬 마을 출구 하나이며, 서쪽 길과 동쪽 다리는 주변 지형입니다.

변경 후 북쪽 왕복, 다리와 개울의 경계, 객체 앞뒤 순서, 줄기·바위 충돌, 몬스터 생성·우회 경로와 전체 지도 표시를 확인하세요.
