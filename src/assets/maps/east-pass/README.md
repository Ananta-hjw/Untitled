# 동쪽 고갯길 아트

2장 고갯길 준비용 아트. OpenAI 이미지 생성 도구로 제작했다.
4800×3200의 독립 맵으로 게임에 연결했다. 동쪽 개울가의 동쪽 출구에서 왕복한다.
`assets.json`은 원화 참고 자료이며 실제 배치·충돌은 `src/world/eastPass.ts`를 따른다.

## 새로 제작한 독립 이미지

| 원본 | 내용 |
| --- | --- |
| `ground.png` | 1536×1024 RGB. 구불구불한 흙길, 평평한 암반·잔돌, 드문 산풀과 빈 쉼터 터. 큰 바위·나무·절벽·건물·불은 지면에 넣지 않았다. |
| `dead-tree.png` | 선 채로 마른 고목. 1024×1536 RGBA. |
| `cliff-straight.png` | 직선 절벽 조각. 1983×793 RGBA. |
| `cliff-corner.png` | 모서리 절벽 조각. 1536×1024 RGBA. |
| `stone-shelter.png` | 앞이 열린 작은 돌 쉼터. 1536×1024 RGBA. 불·인물·짐은 포함하지 않았다. |

원본은 한 장으로 합치지 않는다. 절벽 조각은 배치 시 약간 겹쳐 연결할 수 있지만,
자동으로 빈틈 없이 맞물리는 타일은 아니다. 반대 모서리는 좌우 반전으로 활용할 수 있다.
소품은 기존 `village/props.png`를 화풍 기준으로, 바닥은 남쪽 들판 지면을 기준으로
제작한 뒤 암반과 자갈을 늘려 산길 느낌으로 조정했다.

`python3 tools/build_east_pass_assets.py`는 원본을 보존하며 바닥 WebP와 소품별
WebP 4장, 크기·원점·재사용 목록 `assets.json`을 만든다. 각 소품은 독립 파일이다.
맵의 크기와 소품 크기를 따로 관리해 맵을 확대해도 건물·나무까지 커지지 않게 한다.

## 1장에서 재사용할 그림

- `src/assets/village/props.png` + `frames.json`: `pine`, `rock`, `boulders`,
  `shrub`, `stump`, `sign`. 새 PNG로 복제하거나 다시 그리지 않았다.
- `src/assets/festival/props.webp` + `props.json`: `bonfire-base`, `flame-0`~`flame-3`.
  도르의 작은 불에 맞게 표시 크기를 줄이고, 쉼터와 독립 객체로 배치한다.
- 도르 본인은 기존 `src/assets/characters/dor/`의 원화를 사용한다.

## 충돌·가림 연결 시 기준

- 고목은 줄기와 뿌리만 장애물로 잡고 가지 뒤는 y 깊이 정렬로 가린다.
- 바위는 기존 footprint 방식을 재사용한다.
- 절벽은 전체 암벽 및 위쪽 접근 불가 영역을 다각형/여러 장애물로 막는다.
  직선은 끝을 겹친 자리에 통행 틈이 생기지 않게 하고 모서리는 L자 형태를 따른다.
- 쉼터는 양옆 벽과 뒷벽을 각각 막고 앞 입구는 비운다. 지붕 전체를 충돌로 막지 않는다.
  내부에서는 건물 한 객체를 35%로 흐리게 해 플레이어가 보이게 했다.
  원화는 건물 한 객체이며 지붕·기둥을 별도 레이어로 나누지는 않았다.
- 원화 확대 비율과 같은 변환으로 발 위치·충돌을 변환한다.

## 게임 연결

`eastPass.ts`에 도르, 두 까마귀 무리, 서리 딱정벌레, 출구, 소품, 쉼터 벽 충돌을
모았다. `eastPassArt.ts`는 소품별 WebP와 재사용 모닥불을 읽고 불꽃과 지붕 가림을
게임 시계에 맞춰 갱신한다. 새 맵은 원화와 소품을 독립 크기로 표시하며,
카메라·미니맵·지역 지도는 맵의 `artBounds`를 공유한다.
2장 후속 메인 퀘스트와 나루로 이어지는 출구는 아직 추가하지 않았다.
