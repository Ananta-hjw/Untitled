# 페른의 수레와 여행 상품

이미지 생성 도구로 중세 판타지 RPG풍의 수레 2상태와 상품 아이콘 4종을 제작했다. 기존 로웬 시설의 따뜻한 목재·주황색 차양, 기존 물약과 장비 아이콘의 입체적인 손그림 질감을 기준으로 삼았다. 페른 캐릭터는 기존 원화를 별도로 사용한다.

## 상품 아이콘

| 원본 파일 | 표현 |
| --- | --- |
| `travel-biscuit-source.png` | 리넨 주머니와 구멍이 뚫린 황갈색 건빵 |
| `blue-dew-source.png` | 푸른 액체가 담긴 코르크 마개 유리병과 이슬 모양 장식 |
| `antidote-herb-source.png` | 천과 끈으로 묶은 초록 약초와 작은 꽃봉오리 |
| `travel-cloak-source.png` | 청록색 두꺼운 망토, 모래색 안감과 소박한 청동 걸쇠 |

원본은 각각 1254 × 1254 RGBA PNG다. 게임용 256 × 256 PNG는 상위 `src/assets/items/` 폴더, 같은 크기의 WebP는 `src/assets/icons/items/` 폴더에 있다. 공용 `src/assets/items/icons.webp`·`icons.json`에도 네 ID를 등록해 상점·가방·빠른 사용 칸에서 실제 그림을 재사용한다. 여행자의 망토는 장비창에서도 같은 아이콘을 사용한다.

## 수레

- `src/assets/village/rowen/fern-cart-repaired.png`: 새 덮개로 수리된 수레.
- `src/assets/village/rowen/fern-cart-damaged.png`: 같은 수레의 차양이 잿빛 나방에 삭아 구멍과 해진 가장자리가 생긴 상태. 수리된 원본을 참고한 이미지 편집으로 제작했다.
- 두 원본은 1254 × 1254 투명 RGBA다. 같은 구도와 배치를 유지하고, 차양을 중심으로 상태를 구분했다. 개별 자르기 없이 같은 크기로 줄인 768 × 768 WebP와 공통 프레임 정보 `fern-cart.json`도 준비했다.
- 바퀴·지지대·손잡이와 건빵·푸른 병·약초·접은 망토를 포함한다. 페른·말·남문·초소·바닥은 그림에 포함하지 않았다.

원본과 실행 파일은 `python3 tools/build_fern_assets.py`로 다시 포장한다. 원본 PNG는 보존한다. 투명 영역, 원화의 불투명 실루엣이 캔버스 경계에서 잘리지 않는지, 아이콘의 공용 프레임 등록을 검사했다.

상품 아이콘은 기존 로더에서 사용할 수 있도록 연결했다. 독립 수레는 아직 맵이나 퀘스트 상태 전환에 연결하지 않았다. 기존 남문 시설에 그려진 수레를 유지하고 있으므로, 새 수레를 배치할 때는 중복 표시와 발밑 충돌 영역을 함께 조정해야 한다.
