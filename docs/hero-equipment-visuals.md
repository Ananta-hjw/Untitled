# 주인공 장비 칸 강화 · 승급(`N단계 진화`) 설계

> 기본 5칸(무기·머리·몸·장갑·신발)은 **강화(능력치)** 와 **승급(외형 진화 + 승급 보너스)** 을 분리해 운영하고, **장신구 2칸**만 유품·부적 교체형으로 유지한다.
> 무기 1단계 진화는 **1장 완료 `도란의 검`** 외형으로 적용되며, 그 외 2~5단계 무기와 1~5단계 방어구 외형은 추후 사용자가 직접 확정할 예정이므로 **`N단계 진화`** 로 표기한다.

---

## 1. 강화 vs 승급 핵심 규칙 (`src/items/equipment.ts`)

| 구분 | 비용 | 상한 | 효과 | 외형 변화 |
|---|---|---|---|---|
| **강화 (`enhance`)** | **골드만 필요** (단계가 높을수록 비용 가파르게 상승) | **제한 없음** (`+0, +1, +2, ...`) | 매 `+1`마다 해당 칸 능력치 상승 | **없음** (능력치만 상승) |
| **승급 (`rank`)** | **골드 + 재료** (`슬라임 점액`, `철광석 조각`, `청동 주괴`, `공명 광석`) | `0`(기본) ~ `5`(`5단계 진화`) | 큰 폭의 승급 능력치 보너스 | **무기**: 승급 즉시 외형 진화<br>**방어구**: 4부위 승급이 모두 일치할 때마다 외형(색) 진화 |
| **장신구 2칸** | 구매/퀘스트 유품 | 교체 장착 | 유품·부적 능력치 | 인벤토리/장비창 교체 |

---

## 2. 외형 변화 규칙

### ① 무기 (`weapon`)
- **강화 (`+N`)**: 외형 변화 없음(공격력만 증가).
- **승급 (`rank.weapon`)**: 승급할 때마다 즉시 외형이 진화한다(`src/entities/weaponPose.ts`의 `weaponVisualForRank`).
  - `0단계 (기본)`: 기본 나무검
  - **`1단계 진화`**: **`도란의 검` 외형** *(1장 끝 메인 퀘스트 `도란의 검` 완료 시 도란이 무료로 1회 승급!)*
  - **`2단계 진화` ~ `5단계 진화`**: 외형 추후 확정 *(현재 임시 장검 외형)*

### ② 방어구 (`head` · `body` · `hands` · `feet`)
- 4부위(`머리` · `몸` · `장갑` · `신발`)의 승급 단계가 **모두 같은 단계 이상**에 도달할 때마다 방어구 외형(색)이 바뀐다:
  - `armorAppearanceRank(gear) = min(rank.head, rank.body, rank.hands, rank.feet)`
  - 예: 3부위가 `1단계`이고 신발만 `0단계`면 여전히 `기본` 외형. 신발까지 `1단계`가 되어 **전부 `1단계`** 가 되면 **방어구 `1단계 진화`** 외형 해금!
  - 마찬가지로 **전부 `2단계`** 가 되면 **방어구 `2단계 진화`**, ..., **전부 `5단계`** 가 되면 **`5단계 진화`**.

---

## 3. 승급 재료 및 대장간·스토리 연동

| 승급 단계 | 무기 / 방어구 골드 | 필요 재료 | 재료 획득처 |
|---|---|---|---|
| `0 → 1단계 진화` | `200 G` / `150 G` | `철광석 조각 ×2` + `슬라임 점액 ×2` | 슬라임(`점액`), 1장 권속·나방·보스(`철광석 조각`) |
| `1 → 2단계 진화` | `500 G` / `380 G` | `청동 주괴 ×3` + `철광석 조각 ×2` | 2장 갈대밭 마물·안개 환영·늪의 큰 마물(`청동 주괴`) |
| `2 → 3단계 진화` | `1,100 G` / `850 G` | `공명 광석 ×3` + `청동 주괴 ×3` | 3장 이후 상위 몬스터·보스(`공명 광석`) |
| `3 → 4단계 진화` | `2,200 G` / `1,700 G` | `공명 광석 ×6` + `청동 주괴 ×4` | 3장 이후 상위 몬스터·보스 |
| `4 → 5단계 진화` | `4,000 G` / `3,200 G` | `공명 광석 ×10` + `철광석 조각 ×5` | 후반부 지역 |

- **도란의 대장간 (`doran`)** · **마르타의 대장간 (`marta`)**: 모두 **`강화` / `승급` / `장신구` / `판매`** 4개 탭을 제공한다.
- **스토리 승급 이벤트**:
  - **1장 끝 (`도란의 검`)**: 도란이 시온의 **무기 칸을 1회 무료 승급**해 `1단계 진화 (도란의 검)` 외형으로 바꾼다.
  - **2장**: 별도의 자동 승급 이벤트는 없다(대장간에서 골드+재료로 직접 승급).
- **페른의 수레 (`fern`)**: 행상인이므로 강화·승급 없이 `여행 물품` + `여행 장신구`만 거래한다.
