# 동쪽 고갯길 맵 크기

동쪽 고갯길은 4800×3200 픽셀 원화를 사용한다. 같은 크기의 월드에서
1600×1600 WebP 조각 여섯 장을 원화에서 잘라낸 위치에 배치한다.
`python3 tools/build_east_pass_assets.py`가 지면 조각과 `assets.json`의 좌표를 생성한다.

| 항목 | 로웬 주변 공용 지면 | 동쪽 고갯길 |
| --- | --- | --- |
| 지면 픽셀 크기 | 3432×2288 | 4800×3200 |
| 32단위 길찾기 격자 상한 | 108×72 = 7776칸 | 150×100 = 15000칸 |

실제 통행 가능 영역은 맵별 다각형과 장애물로 정한다. 고갯길의 이동 경계,
출구·소품 좌표는 `src/world/eastPass.ts`에 정의한다.
카메라와 미니맵은 같은 맵의 `artBounds`를 사용한다.

새 맵은 목표 월드 크기의 픽셀 원화를 제작하고 지면과 소품을 별도로 배치한다.
큰 바닥은 원화에서 잘라낸 조각을 이어서 표시한다. 4800×3200 전체를 RGBA로
풀었을 때 약 58.6 MiB이며, 조각 각각의 크기는 기기 텍스처 한도 안에 들어야 한다.
